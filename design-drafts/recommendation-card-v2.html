设计决策说明

🎯 核心思路：渐进式信息披露
表层卡片 回答三个问题：这是什么？（标题 + 关键词）· 谁写的？（作者 + 来源）· 值得看吗？（评分 + 添加数）。用户可在 5 秒内完成扫描决策。
详情弹窗 回答"为什么值得看"——中文介绍、原文摘录、源链接。通过右上角"详情"按钮触发，以弹窗形式呈现，不破坏列表浏览上下文。
📐 信息分层逻辑
表层（即时可见）：标题（英文 + 中文）→ 作者/来源 → 关键词 → 底部栏（左：推荐值+人数 / 右：加入按钮）→ 右上角：详情按钮
弹窗详情：标题回顾 → 中文介绍 → 原文摘录 → 源链接（可点击跳转）
🔤 双语标题设计
英文标题使用 Playfair Display 17px Bold 作为主视觉层级——这是英语学习者最关心的信息。中文标题以 13px 常规字重、ink-muted 颜色 作为辅助说明，不抢占视觉焦点。
📍 详情按钮在右上角
详情是次要操作（主要操作是"加入书架"），放在右上角不干扰主操作流。位置固定、始终可见，用户扫完标题和标签后自然向右上看。使用小号字体 + 低调边框，不喧宾夺主。
🪟 弹窗 vs 原地展开
弹窗的优势：(1) 内容空间更大，不挤占列表高度；(2) 半透明背景 + 模糊遮罩让用户聚焦详情内容；(3) 关闭弹窗回到列表时位置不变，不丢失浏览进度；(4) 视觉上更正式、更有"沉浸阅读"的感觉。
📊 社交证明
推荐值（金色数字）+ 添加人数——放在左下角，"加入"按钮放在右下角，两者水平对齐，形成"数据支撑决策 → 立即行动"的自然眼动路径。
💬 摘录的呈现
使用 Lora 斜体 + 金色左边框——这是阅读体验的缩影，让用户在弹窗中先感受原文风格。这符合语言学习场景的独特需求。
🎨 视觉风格连续性
完全保留现有设计系统的 tokens：parchment 背景、ink 色系、gold 强调色、Playfair Display / Lora / DM Sans 字体栈、圆角、过渡动画。弹窗样式与现有 SubmitRecommendationModal 保持一致。
