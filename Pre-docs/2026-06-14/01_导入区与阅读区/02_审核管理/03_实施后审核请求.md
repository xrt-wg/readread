5. deleteImportItem → RPC 执行，articles.source_import_id = NULL，import_items.deleted_at 非空
```

### A.6 端到端完整流程

```
1. 登录 → 书架 → URL导入 → 素材列表出现

3. 移入阅读区 → 文章库出现文章
4. 打开文章 → 阅读 → 划词收藏 → 标记进度

7. 删除素材 → 确认弹窗 → 两篇文章来源标签消失
