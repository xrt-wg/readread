## 变更摘要

ReadRead 从"本地+云端混合"架构过渡为"纯云端优先"架构：

1. **移除用户可见的迁移功能** — `pending_migration` 状态不再产生，迁移 UI 不再渲染
2. **新用户首页精简** — Hero 仅保留「立即体验」按钮，移除「导入」和「导入备份」
3. **试用阅读 + 功能门控** — 匿名用户可阅读示例文章、使用划词翻译，但收藏/标记/导入/回顾需登录
4. **登录后静默数据导入** — localStorage 中的试用数据在注册时自动导入云端

## 需要特别关注的边界场景

1. **网络离线** — 匿名用户离线时点击「立即体验」，localStorage 写入是否正常？注册时无网络如何处理？
2. **多标签页** — 匿名用户在一个标签页阅读，另一个标签页注册，数据一致性？
3. **浏览器隐私模式** — localStorage 在隐私模式下可能受限，试用体验如何降级？
4. **Supabase 未配置** — 当 `VITE_SUPABASE_URL` 缺失时，匿名用户能否仍然试用？
5. **已有 localStorage 旧数据的老用户** — 之前积累了大量本地数据的用户，登录后静默导入是否会导致超时或性能问题？
