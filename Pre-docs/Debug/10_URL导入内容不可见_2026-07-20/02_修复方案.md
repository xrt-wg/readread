## 有效性原理

传入 `canUseCloudLibrary` 后：

```
修复前：
  createReading(result, { userId, origin: 'imported' })
    → useCloudSource({ canUseCloudLibrary: undefined, userId })
    → false → localStorage ❌

修复后：
  createReading(result, { userId, origin: 'imported', canUseCloudLibrary })
    → useCloudSource({ canUseCloudLibrary: true, userId })
    → true → Supabase readings 表 ✅
```

`createReading` 内部逻辑：
```js
if (!useCloudSource({ canUseCloudLibrary, userId })) {
    return articleStore.save(legacyArticle)   // localStorage 分支
}
// Supabase 分支
const { data, error } = await client.from('readings').insert(reading).select(READING_COLUMNS).single()
```

修复后走 Supabase 分支，数据写入 `readings` 表。随后 `fetchImportItems` 从同一张表查询，立即可见。
