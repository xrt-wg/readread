## 2. 修复后行为对照

| 场景 | 修复前 | 修复后 |
| --- | --- | --- |
| DeepSeek 思考耗尽 max_tokens | 200 空串 → 以 done 落库，永久静默 | 思考已关闭；若仍空则 500 → 降级 kimi → 直译 |
| 有道/DeepL 200 但词义为空 | 空串透传，弹窗空白/卡片空落库 | 500 或前端抛错 → 降级 MyMemory |

| 同词重复划选 | 重复完整请求 | 缓存命中秒出 |
