## 一、审核说明

### 1.1 审核目标

对照修订后的修复方案，逐项验证实施成果，确保：

- 引用块在阅读区与书架预览观感一致（间距平衡、无多余外壳），且收藏/段落序号不回归
- 段落下边距全库三处统一收敛，阅读区内部分裂消除
- frontmatter 在预览与阅读区呈现一致（镜像引用块，而非隐藏）
- 列表项与标题随阅读字号缩放，与预览排版令牌对齐
- 列表项目符号恢复（F-1）
- 无新增硬编码颜色、无数据库迁移、收藏/划选/阅读标记无回归

### 1.2 审核方式

| 标记 | 含义 |
|------|------|
| ✅ 通过 | 实施完全符合方案，无遗留问题 |
| ⚠️ 有条件通过 | 实施基本符合，存在已知、可接受的偏差 |
| ❌ 不通过 | 实施与方案存在实质偏差，需修复后重审 |

## 九、附录：快速验证清单

**引用块（I-1）**
1. 阅读区打开含单段/多段引用块的文章 → 上下紧凑、无底部空档，与书架预览一致
2. 引用块内划选收藏 → 高亮生效、位置不偏移
3. 普通段落 hover 仍显示「标记读到这里」按钮；引用块内不再显示

**段落下边距（I-4）**
4. 书架预览 / 只读预览 / 阅读区纯文本 段落间距与阅读区 markdown 一致（1.8em）

**frontmatter（I-5）**
5. 书架预览打开含 frontmatter 文章 → 顶部显示引用块，正文不含 `---` 裸显，与阅读区一致

**字号（I-3）**
6. 阅读区调节字号 → 段落、列表项、标题同步缩放；列表项与正文同字号

**列表符号（F-1）**
7. 阅读区/预览的 `- 列表` 显示圆点、`1. 列表` 显示序号
