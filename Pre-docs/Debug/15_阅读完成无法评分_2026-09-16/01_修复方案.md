# 修复方案：阅读完成无法评分

- 日期：2026-09-16
- 前置：根因已确证，见 `00_问题分析报告.md`（§2、§3）
- 范围：仅修复「阅读完成时评分组件不可见」；不触碰评分服务层、数据模型、推荐列表卡片（入口 ① 未实现属设计缺口，见 §4 边界）

---

## 1. 根因（一句话）

`handleMarkCompleted` 在读完标记后同步调用 `onBack()`（`src/components/ReaderPage.jsx:584`），阅读页立即卸载，评分组件未及渲染即随页面销毁——来自推荐区的内容读完时被直接踢回书架，无机会评分。

---

## 2. 核心修复：读完时条件性停留 + 补充返回出口

文件：`src/components/ReaderPage.jsx`（`handleMarkCompleted` 一处条件改动 + 「已读完」态新增返回按钮）。

### 2.3 选型理由

| 维度 | 说明 |
| --- | --- |
| 最小改动 | 仅 `handleMarkCompleted` 一处条件 + 「已读完」态一处返回按钮；评分组件渲染逻辑、`useEffect`、评分服务层、数据模型全部不动 |
| 精确命中根因 | 只对「来自推荐区且读完」的内容改变行为，其余内容维持 D2 的「读完即返回」 |
| 自洽 | 停留后 `useEffect`（`ReaderPage.jsx:218-228`）天然补上 `recSubmissionId`，无需手动前置设置 |
| 无回归风险 | 非推荐区内容走原 `onBack()` 分支，行为完全不变 |

### 2.4 备选方案（未采用）

| 方案 | 思路 | 未采用原因 |
| --- | --- | --- |
| B：读完统一停留，不区分来源 | 所有内容读完都停住，用户手动返回 | 改变所有内容的读完 UX，违背 D2 决策；对无评分能力的普通内容多一步无意义操作 |
| C：评分入口移到书架列表卡片 | 在推荐区卡片上做评分（需先读完），阅读页不动 | 改动面大（新组件 + 资格校验 UI + 卡片状态）；且偏离用户主诉「阅读完成时评分」；可作独立后续项 |
| D：读完弹评分引导窗（Modal） | 读完时弹 Modal 引导去评分 | 引入新交互形态，与现有内联评分组件重复；内联停留已足够 |

### 2.5 结论

**采用方案 A（2.1 + 2.2）**：一处条件改动 + 一处返回按钮，根因级修复，向后兼容。

## 3. 验证与回归

1. **推荐区内容读完（主路径）**：
   - 加入推荐区内容 → 打开阅读 → 读完点「标记已读完」→ **停留在阅读页**，出现「已读完」badge + 评分组件 + 「返回书架」按钮。
   - 点「推荐 / 一般 / 不行」→ 评分高亮，`getMyRating` 回显正确；改评分 → 高亮切换。
   - 点「返回书架」→ 回到书架，该条 `recommend_score` / 评分分布已随评分更新（列表按 score 重排）；`add_count` 不随评分变化，仅随加入书架变化。
2. **非推荐区内容读完（回归）**：导入文章读完 → 点「标记已读完」→ **照旧立即返回书架**（行为不变）。
3. **再次打开已完成推荐区文章（回归）**：书架打开已完成文章 → 「已读完」badge + 评分组件 + 返回按钮均出现，评分回显当前值。
4. **评分资格边界**：未加入书架 / 未读完的内容不应出现评分组件（条件 ③④ 未满足时 `recSubmissionId` 为 null，组件不渲染）。
5. **推荐区内容但 `shareSourceId` 为空（数据残缺 / 迁移残留）**：读完点「标记已读完」→ 应**照旧立即返回书架**，不出现「停留却无评分」的边界态（对应 P1 补正后的对齐）。
6. **评分后返回书架（add_count 不随评分变）**：观察推荐列表该条——`recommend_score` / 评分分布变化，`add_count` 不变化（对应 P2）。

## 4. 边界与不做的事

- **不实现**设计文档入口 ①（推荐列表卡片评分分布 + 评分交互）——属独立设计缺口，本次不展开（见分析报告 §4.1）。
- **不处理**推测 B1（`origin` 为 null 被 fallback 为 `imported`）/ B2（localStorage 路径丢 `origin` / `shareSourceId`）——仅当验证「再次打开仍不显示」时再排查；本次未确证为根因。
- **评分后不自动返回**——停留让用户看到评分高亮，手动「返回书架」；避免引入「评分即跳转」的额外时序判断。
- **不动** `setReadingMarkCompleted` / `returnToShelf` / `rateRecommendation` / `getMyRating` 及数据库触发器与 RPC。
