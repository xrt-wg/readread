# 修复方案：表格、标题、引用文本无法标注

**日期**：2026-08-06
**关联分析**：[00_问题分析报告.md](00_问题分析报告.md)

---

## 一、设计原则

1. **不改段落计数系统**：`getParagraphs()` 和 `paraIdxRef` 逻辑不动，已有书签的 `paragraphIndex` 不变 → 零破坏
2. **最小改动面**：仅改 2 个文件，改动集中在渲染层和事件层
3. **降级优雅**：`data-para-index` 仍是首选锚点；仅在找不到时使用新的块级元素定位

---

## 二、方案概述

核心思路：让 `handleMouseUp` 在找不到 `data-para-index` 时，**不一路走到 `null`**，而是停在最近的块级内容元素（标题、表格单元格等），从其 `textContent` 中提取选区上下文。

当前流程：
```
<td> → <tr> → <tbody> → <table> → … → null ❌
```

修复后：
```
<td> → 命中 BLOCK_TAGS → 停止 ✅（取 textContent 作为 paraText）
```

---

## 三、改动清单

### 3.1 `ReaderPage.jsx` — `handleMouseUp` DOM 游走逻辑

**文件**：[src/components/ReaderPage.jsx](src/components/ReaderPage.jsx)

**现状**（L178-L187）：
```javascript
let anchorEl = range.startContainer.nodeType === Node.TEXT_NODE
  ? range.startContainer.parentElement
  : range.startContainer
while (anchorEl && anchorEl.dataset?.paraIndex === undefined) {
  anchorEl = anchorEl.parentElement
}
if (anchorEl?.dataset?.paraIndex !== undefined) {
  paraIndex = parseInt(anchorEl.dataset.paraIndex)
}
```

条件 `anchorEl.dataset?.paraIndex === undefined` 对于 `<td>`、`<h1>` 等元素永远为 `true` → 一直上溯到 `null`。

**改动**（L178-L200 区间，约 12 行）：

```javascript
// 块级内容标签：即使没有 data-para-index，也是有效的内容容器
const CONTENT_BLOCK_TAGS = new Set([
  'P', 'LI', 'H1', 'H2', 'H3', 'H4', 'H5', 'H6',
  'TD', 'TH', 'BLOCKQUOTE', 'PRE', 'FIGCAPTION',
])

// 选区定位：先找 data-para-index；找不到则停在第一个 CONTENT_BLOCK_TAGS 元素
let anchorEl = range.startContainer.nodeType === Node.TEXT_NODE
  ? range.startContainer.parentElement
  : range.startContainer

// 标记是否走的是块级内容回退路径（-1 vs 有效 paraIndex）
let contentBlockEl = null

while (anchorEl && anchorEl.dataset?.paraIndex === undefined
       && !CONTENT_BLOCK_TAGS.has(anchorEl.tagName)) {
  anchorEl = anchorEl.parentElement
}

if (anchorEl?.dataset?.paraIndex !== undefined) {
  paraIndex = parseInt(anchorEl.dataset.paraIndex)
} else if (anchorEl && CONTENT_BLOCK_TAGS.has(anchorEl.tagName)) {
  // 回退：停在了非段落块级元素（标题 / 表格单元格 / blockquote 等）
  contentBlockEl = anchorEl
  paraIndex = -1
}

// ...后续...

// paraText 构造：优先从 contentBlockEl 取（回退路径），
// 否则从 anchorEl 取（data-para-index 路径），最后兜底 paragraphs[0]
const paraText = (contentBlockEl?.textContent)
  || (anchorEl?.textContent)
  || (paragraphs[paraIndex >= 0 ? paraIndex : 0] ?? '')
```

**有效性原理**：

| 选区位置 | `anchorEl` | `paraIndex` | `paraText` | 效果 |
|---------|-----------|-------------|------------|------|
| 表格 `<td>` | `<td>` | `-1` | cell.textContent | ✅ 弹窗出现，contextSentence 从 cell 文本正确推导 |
| 标题 `<h1>` | `<h1>` | `-1` | heading.textContent | ✅ 同上 |
| 普通 `<p>` | `<p>` (有 `data-para-index`) | 原值 | p.textContent | ✅ 不受影响 |
| 列表 `<li>` | `<li>` (有 `data-para-index`) | 原值 | li.textContent | ✅ 不受影响 |
| blockquote 内 `<p>` | `<p>` (有 `data-para-index`) | 原值 | p.textContent | ✅ 不受影响 |

`paraIndex = -1` 含义：此收藏不在 `paragraphs` 数组索引范围内，属"非段落内容"。在收藏列表中，这些书签的段落跳转功能可静默降级（即不执行 scrollIntoView），不影响其他功能。

### 3.2 `SectionFlow.jsx` — 标题组件增加 Bookmark 按钮

**文件**：[src/components/SectionFlow.jsx](src/components/SectionFlow.jsx)

**现状**（L89-L92）：
```javascript
h1: ({ children }) => <h1 className="article-h1">{children}</h1>,
h2: ({ children }) => <h2 className="article-h2">{children}</h2>,
h3: ({ children }) => <h3 className="article-h3">{children}</h3>,
h4: ({ children }) => <h4 className="article-h4">{children}</h4>,
```

标题只渲染纯 HTML 标签，无左侧 Bookmark 按钮、无 `data-para-index`、无 `ParagraphRenderer`。

**改动**（4 个组件统一模式，以 `h2` 为例）：

```javascript
h2: ({ children }) => {
  const idx = paraIdxRef.current++  // 参与索引计数，与 paragraphs 数组对齐
  const rawText = extractRawText(children)
  const paraBMs = bookmarksRef.current.filter((b) => b.paragraphIndex === idx)
  const isMarked = isMarkedPara(readingMark, sectionId, idx)
  return (
    <div className="group relative" style={{ marginTop: '1.5em', marginBottom: '0.5em' }}>
      <button
        onClick={() => onSetReadingMarkRef.current(idx)}
        title={isMarked ? '取消阅读标记' : '标记读到这里'}
        className={isMarked ? '' : 'opacity-0 group-hover:opacity-100 transition-opacity duration-150'}
        style={{
          position: 'absolute',
          left: '-32px',
          top: '50%',
          transform: 'translateY(-50%)',
          background: 'none',
          border: 'none',
          cursor: 'pointer',
          padding: '4px',
          borderRadius: '6px',
          color: isMarked ? 'var(--gold)' : 'var(--ink-muted)',
        }}
      >
        <Bookmark size={14} fill={isMarked ? 'currentColor' : 'none'} />
      </button>
      <h2 className="article-h2" data-para-index={idx}>
        <ParagraphRenderer text={rawText} bookmarks={paraBMs} onHoverBookmark={onHoverRef.current} />
      </h2>
    </div>
  )
},
```

`h1`/`h3`/`h4` 同理，margin 值沿用现有 CSS（[index.css:296-299](src/index.css#L296-L299)）中各自定义的 `margin`。Bookmark 按钮结构完全复刻 `p` 组件（[SectionFlow.jsx:53-87](src/components/SectionFlow.jsx#L53-L87)）。

**注意**：`paraIdxRef.current++` 会使标题占据一个索引位置。这意味着 `getParagraphs()` 也需要同步修改，使其**也计入标题**，否则段落索引错位。

### 3.3 `progress.js` — `getMarkdownParagraphs` 不再跳过标题

**文件**：[src/services/progress.js](src/services/progress.js)

**现状**（L61）：
```javascript
if (/^#{1,6}\s/.test(block)) continue  // h1-h6 标题
```

**改动**：删除此 skip，使标题行正常计入 `paragraphs` 数组。

同步检查：标题文本行在去除 `#` 前缀后直接作为段落入数组。格式如 `"## 标题文字"` → 存入 `paragraphs[idx]` 为 `"标题文字"`。

```javascript
// 删除此行：
// if (/^#{1,6}\s/.test(block)) continue

// 改为：标题也作为段落（保留原始文本，去除 # 前缀和首尾空白）
if (/^#{1,6}\s/.test(block)) {
  paragraphs.push(block.replace(/^#{1,6}\s+/, '').trim())
  continue
}
```

**影响面评估**：`paragraphs` 数组长度增加 N（标题数量）。已有书签的 `paragraphIndex` 如果指向标题**之后**的段落，其索引值会因标题插入而整体偏移，**导致已有书签高亮错位**。

**这是一个破坏性改动，需要谨慎权衡。**

## 四、改动边界

### 要做

1. `handleMouseUp` DOM 游走：增加 `CONTENT_BLOCK_TAGS` 回退路径
2. 标题组件：增加 `data-para-index`、左侧 Bookmark 按钮、`ParagraphRenderer`
3. `getMarkdownParagraphs`：标题行不再跳过，纳入 `paragraphs` 数组

### 不做

- 表格单元格不加左侧 Bookmark 按钮（"标注读到这里"在 cell 粒度上没有语义）
- 表格单元格不加 `ParagraphRenderer`（cell 粒度的高亮过于碎片化，留后续迭代）
- blockquote 本身不改动（已验证 `<p>` 有 `data-para-index`）

---

## 五、风险与取舍

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| 标题纳入 paraIdxRef 导致已有书签索引偏移 | **高** | 需评估已有书签量；若线上无存量可接受；若有，需写迁移脚本重算所有 `paragraph_index` |
| `CONTENT_BLOCK_TAGS` 白名单不完整 | 低 | 先用已知集合覆盖，后续按需扩展 |
| `paraIndex = -1` 的收藏在列表中"跳转到段落"不可用 | 低 | 按钮静默禁用或隐藏，边界已覆盖 |

---

## 六、替代方案（风险更低）

若标题纳入 `paraIdxRef` 的索引偏移风险不可接受，标题可走**独立索引体系**：

- 标题 `data-para-index` 设为其所在 section 内的标题序号（如 `"h_0"`, `"h_1"`），不与段落索引混用
- `handleMouseUp` 在 `anchorEl.tagName` 匹配 `H1`-`H6` 时，`paraIndex` 设为 `-1`，`paraText` 取自 `anchorEl.textContent`
- 不给标题加左侧 Bookmark 按钮（标注"读到这里"仅对段落有意义）
- 不修改 `getParagraphs()`

| 维度 | 主方案 | 替代方案 |
|------|--------|---------|
| 标题可划选收藏 | ✅ | ✅ |
| 标题可标注"读到这里" | ✅ | ❌（放弃） |
| 已有书签索引偏移 | ⚠️ 有风险 | ✅ 零风险 |
| `getParagraphs()` 改动 | 需要 | 不需要 |
| 复杂度 | 中 | 低 |
