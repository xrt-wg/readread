# 修复记录：摘录推荐详情展示中文

> 日期：2026-07-10
> 状态：已修复，测试通过

---

## 1. 问题

推荐详情弹窗中，摘录的"原文"区域显示中文翻译，英文原文从未出现。

## 2. 根因

`RecommendationDetailModal.jsx:27` — `displayExcerpts` 字段优先级为「有翻译则取翻译」，AI 改造后 `excerptsTrans` 永远有值，导致中文覆盖英文展示位。

## 3. 修复

| 文件 | 行号 | 改动 |
|------|------|------|
| `src/components/RecommendationDetailModal.jsx` | 27-28 | `displayExcerpts` 优先级从 `excerptsTrans` 优先反转为 `excerpts` 优先 |

```diff
- const displayExcerpts = rec.excerptsTrans && rec.excerptsTrans.length > 0 ? rec.excerptsTrans : rec.excerpts
+ // 优先展示英文原文，翻译作为辅助展示在下方
+ const displayExcerpts = rec.excerpts && rec.excerpts.length > 0 ? rec.excerpts : rec.excerptsTrans
```

## 4. 验证

- [x] AI 生成的新推荐 — 详情弹窗中摘录原文显示英文、翻译显示中文
- [x] 手动修改摘录后重新提交 — 详情弹窗展示一致

## 5. 影响范围

仅 1 行变更，无其他文件受影响。向后兼容旧数据（`excerptsTrans=null`）。
