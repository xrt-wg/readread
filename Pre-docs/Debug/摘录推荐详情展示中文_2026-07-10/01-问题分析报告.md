# 问题分析：推荐详情弹窗中摘录原文显示中文

> 日期：2026-07-10
> 状态：已定位

---

## 1. 问题描述

提交推荐后，在推荐区打开推荐详情弹窗，摘录区域的"原文"显示的是**中文翻译**而非英文原文。

**预期**：原文展示英文 verbatim 摘录，下方展示中文翻译。

**实际**：原文位置和翻译位置均显示中文，英文摘录从未出现。

---

## 2. 数据流追踪

逐环节验证字段是否发生交换：

| 4 | 弹窗 state | `SubmitRecommendationModal.jsx:205-206` | `result.excerpts` | `result.excerpts_trans` | 无交换 |
| 5 | 提交调用 | `SubmitRecommendationModal.jsx:279-280` | `excerpts` → 参数 | `excerptsTrans` → 参数 | 无交换 |

## 4. 根因定位

[`RecommendationDetailModal.jsx` 第 26-27 行](src/components/RecommendationDetailModal.jsx#L26-L27)：

```js
const hasExcerpts = (rec.excerptsTrans && rec.excerptsTrans.length > 0)
  || (rec.excerpts && rec.excerpts.length > 0)

const displayExcerpts = rec.excerptsTrans && rec.excerptsTrans.length > 0
  ? rec.excerptsTrans   // 🔴 优先取中文翻译作为"主展示文本"
  : rec.excerpts        // 仅当无翻译时才用英文原文
```

然后第 140-158 行用 `displayExcerpts` 渲染在 serif italic 样式的"原文"区域，同时第 150-157 行用 `rec.excerptsTrans[i]` 渲染下方的翻译行。

**结果**：
- 主展示文本 = `excerptsTrans` = 中文（以原文样式呈现）
- 翻译行 = `excerptsTrans[i]` = 也是中文
- `excerpts`（英文）从未出现在页面上

---

## 5. 为什么之前没问题

旧的提交流程中，用户手写提交只填 `excerpts`（英文），`excerptsTrans` 始终为 `null`。第 27 行的三元表达式始终走 `else` 分支，展示英文原文。

AI 改造后，`excerptsTrans` 永远有值（AI 自动生成中文翻译），三元表达式永远走 `if` 分支，中文覆盖了英文展示位。

---

## 6. 受影响范围

| 展示位置 | 是否受影响 | 说明 |
|---------|-----------|------|
| 推荐详情弹窗 `RecommendationDetailModal` | **是（根因）** | `displayExcerpts` 字段优先级错误 |
| 推荐列表卡片 `ImportPage.jsx` | 否 | 卡片不展示摘录，仅展示 intro |
| 提交弹窗查看模式 `SubmitRecommendationModal` | 否 | 使用正确的 `excerpts` / `excerptsTrans` 分开展示 |
| 提交弹窗编辑模式 `SubmitRecommendationModal` | 否 | 使用正确的 `excerpts` / `excerptsTrans` 分开展示 |

---

## 7. 结论

**根因唯一**：`RecommendationDetailModal.jsx:27` 中 `displayExcerpts` 的字段选取优先级为“有翻译则取翻译”，与当前的"英文原文 + 中文翻译"双字段语义冲突。

**无其他问题**：整个数据写入链路的 7 个环节均无字段交换，DB 数据已证实正确。
