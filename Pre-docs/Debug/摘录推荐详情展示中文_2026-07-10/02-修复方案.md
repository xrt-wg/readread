# 修复方案：推荐详情弹窗摘录展示

> 日期：2026-07-10
> 关联问题分析：[01-摘录推荐详情展示中文的问题分析.md](01-摘录推荐详情展示中文的问题分析.md)

---

## 1. 问题根因

[`RecommendationDetailModal.jsx:27`](src/components/RecommendationDetailModal.jsx#L27)：

```js
// 当前逻辑（错误）
const displayExcerpts = rec.excerptsTrans && rec.excerptsTrans.length > 0
  ? rec.excerptsTrans   // 优先取中文
  : rec.excerpts
```

在 AI 改造前，`excerptsTrans` 始终为 `null`，此逻辑无问题。AI 改造后 `excerptsTrans` 永远有值，导致中文覆盖了英文展示位。

---

## 2. 修复方案

### 改 1：交换主展示字段（核心修复）

```diff
  const hasExcerpts = (rec.excerptsTrans && rec.excerptsTrans.length > 0)
    || (rec.excerpts && rec.excerpts.length > 0)

- const displayExcerpts = rec.excerptsTrans && rec.excerptsTrans.length > 0
-   ? rec.excerptsTrans
-   : rec.excerpts
+ // 优先展示英文原文，翻译作为辅助
+ const displayExcerpts = rec.excerpts && rec.excerpts.length > 0
+   ? rec.excerpts
+   : rec.excerptsTrans
```

### 改 2：中英同时存在时展示原文 + 翻译对照（增强修复）

当前第 140-158 行的展示逻辑只在 `rec.excerptsTrans[i]` 存在时追加翻译行。修复后变为：始终展示英文 `displayExcerpts` 作为原文，当 `excerptsTrans` 存在时在下方追加中文翻译。

但当前代码已有此逻辑（第 150-157 行对 `rec.excerptsTrans[i]` 的检查），只需修复 `displayExcerpts` 的计算即可同时满足新旧数据：

| 场景 | `excerpts` | `excerptsTrans` | 修复后展示效果 |
|------|-----------|----------------|--------------|
| AI 生成的新数据 | 英文 3 条 | 中文 3 条 | 原文=英文 + 下方翻译=中文 |
| 旧手写数据 | 英文 1-5 条 | null | 原文=英文（无翻译行） |
| 旧迁移数据 | null | 中文 | 原文=中文 + 翻译行=同样的中文（轻微重复——极端场景，正常 AI 流程不会产生） |

## 6. 可选增强（P4，v1 不做）

当 `excerpts` 为 null/空但 `excerptsTrans` 有值时（仅存在于假设性的历史迁移数据），修复后 L150 的翻译守卫仍然为 true，导致同一条中文在"原文"和"翻译"位置各渲染一次。

如需彻底消除此边界情况，可将翻译行守卫收紧：

```js
// 当前守卫（L150）
{rec.excerptsTrans && rec.excerptsTrans[i] && (
  <p>...</p>
)}

// 收紧为（仅在英文原文存在时才展示翻译）
{rec.excerptsTrans && rec.excerptsTrans[i] && rec.excerpts && rec.excerpts[i] && (
  <p>...</p>
)}
```

**v1 不实现**：此场景在正常 AI 提交流程中不会发生（提交校验守卫阻止全空 `excerpts`），且旧迁移数据极少。当前修复已覆盖所有实际场景，此项为理论完备性增强，由后续迭代决定。
