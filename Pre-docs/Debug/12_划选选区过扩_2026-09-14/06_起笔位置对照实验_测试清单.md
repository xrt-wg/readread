# 起笔位置对照实验 — 测试清单与记录表

> **日期**：2026-09-15
> **目的**：验证「边界危险区」假说（05 报告第二节）：过扩是否只在**起笔落点位于已收藏词与后续空格交界处附近**时触发。
> **判别逻辑**：若危险区假说成立，则从目标词**首字正中**起笔应几乎不发作，而从**词前空格边缘**起笔应高发。两组差异显著即确认。
> **前置文档**：`05_选区粘黏场景_分析更新_2026-09-15.md` 第四节第 2 条

---

## 一、测试前准备

- [ ] 环境记录（与 04 清单同表）：日期/时段、浏览器及版本、网络、存储路径（云端/本地）、测试模式（预读/非预读，全程不变）。
- [ ] **测试场地构造**：先收藏一批词，制造出 ≥20 个「已收藏词 + 空格 + 未收藏词」的相邻结构（目标词与已收藏词同句同段、仅隔一个空格）。收藏词之间留出足够间隔，避免大段高亮连片改变手感。
- [ ] 打开收藏列表面板放旁边（发作的客观判据：出现大段误收藏）。
- [ ] **建议 C、D 交替进行**（C×5 → D×5 → C×5 → D×5 …），避免手感漂移污染对照。
- [ ] 若发作产生大段误收藏，**先删除该误收藏条目**再继续下一次。

## 二、C 组：首字正中起笔（对照组，预期几乎不发作）

每次迭代：

1. 选定一个「前面隔着空格、空格前是已收藏词」的目标词；
2. **刻意从目标词第一个字的字形正中按下**，向右拖选该词（起笔点明确避开词前空格）；
3. 完成收藏；
4. 记录：是否发作（选区过扩 / 出现大段误收藏）；顺带记录本次是否出现「吞前导空格」的粘黏（即使未过扩）。

重复 20 次。

## 三、D 组：空格边缘起笔（实验组，预期高发）

每次迭代：

1. 选定同样结构的目标词；
2. **刻意从词前空格处按下**（落在空格上、贴着已收藏词右边缘的危险区），向右拖选该词；
3. 完成收藏；
4. 记录：是否发作；是否先出现「吞空格」再升级为大过扩；若发作，记录误选起点是否段首、是否跨段。

重复 20 次。

> ⚠️ 起笔位置是本实验的唯一变量，两组划选方向（左→右）、速度、目标词结构保持一致。

## 五、结果判读

| 结果 | 判读 |
|------|------|
| C 过扩≈0 且 D 过扩高发（≥5/20） | ✅ 危险区假说确认：触发 = 起笔落点在边界危险区。进入探针/结构隔离阶段（05 报告第四节 1、3） |
| C、D 过扩均高发 | ❌ 与危险区假说矛盾：过扩不依赖起笔位置 → 需重新审视（可能只要「前面紧邻已收藏词」即触发，与落点无关——这本身也是重要信息） |
| C、D 均 ≈0 | ⚠️ 本环境未复现：检查测试场地是否满足「紧邻已收藏词」结构；或换成用户之前能复现的原手势/原文本重试 |
| C 组也「吞空格」但不扩 | 🔶 重要细分：吞空格是普遍的光标解析行为（正常），过扩才是异常 → 说明危险区决定的是「过扩」而非「吞空格」，二者是两级独立现象 |

**附加统计**：D 组中「先吞空格后过扩」 ____ 次；「未吞空格也过扩」 ____ 次。
（若存在「未吞空格也过扩」→ 吞空格不是过扩的必要前兆，机制图像需修正。）

## 六、可选附加：方向翻转测试（05 报告推测 1a）

若 D 组确认高发，追加 10 次：空格边缘起笔后**故意先左移 2–3px 再右拖**。

| 手势 | 过扩次数 / 10 |
|------|--------------|
| 直接右拖（D 组原手势的延续观察） | |
| 先左移 2–3px 再右拖 | |

先左移组显著更高 → 支持「方向翻转触发锚点向祖先内联盒起点吸附」；无差异 → 推翻该子推测，锚点跳变更可能发生在跨越嵌套边界时。
