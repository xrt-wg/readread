## 一、对照实验结果的判读：M-render 降级

M-render（03 报告）的核心可证伪预测：「发作概率依赖异步重渲染窗口与拖选的时间重叠」→ B 组（紧接着）应显著高于 A 组（延迟 5 秒）。

**实验结果不支持该预测** → M-render 作为主要机制**证伪/降级**。
（保留为理论可能：拖选途中 DOM 替换确实会干扰选区，但它不是本问题的主触发路径。）

同时，「选区粘黏在划选过程中实时可见」这一观察**排除了所有「mouseup 时刻才出问题」的机制**（包括硬件 multi-click 误判的最终残余形态）：锚点从划选一开始就已经落在空格之前。

## 二、机制图像修正：位置触发，而非时间触发

### 2.1 触发条件的精确描述

发作需要两个几何条件同时满足：

1. **起笔落点在「边界危险区」**：已收藏词高亮 span（`padding: 1px 1px`，可能嵌套在句下划线 span 内）与后续文本节点（空格）交界处的前后约 1–2px；
2. **该边界紧邻已收藏词**（高亮 span 存在）。

### 2.2 对全部历史证据的统一解释（位置说）

| 历史证据 | 位置说解释 |
|---------|-----------|
| 「收藏后紧接着划选下一个词」高频 | 下一个词**几何上紧邻**刚收藏的词 → 天然处于危险区；与时间无关，故对照实验 A/B 无差异 ✓ |
| 预读模式复现 | 预读划词即收藏、连续划词，频繁处于「紧邻已收藏词起笔」的位置 ✓ |
| 换鼠标现象不变 | 与输入设备无关 ✓ |
| 低频、曾难以复现 | 需起笔恰好落入 1–2px 危险区，概率性事件 ✓ |
| 实验 2：移除 padding 后「更难复现但未消失」 | **重新获得解释力**：padding 把高亮 span 命中区域向两侧各扩 1px，盖住词后空格边缘、**扩大危险区**；移除后危险区变窄（概率下降）但嵌套边界仍在（不彻底）✓ |
| 误选内容 = 前面一大段 | 锚点被吸附到祖先内联盒/段落起点 ✓ |
| 空格被吞、划选过程实时可见 | 锚点从一开始就解析到边界位置（空格之前）✓ |

注意：c82db8c 时间线证据也重新指向结构——双层叠加渲染引入的「嵌套 + padding」正是危险区的构成要素。

### 2.3 机制链（当前最佳图像）

```
起笔落入危险区（高亮 span padding 边缘 / span-文本节点边界）
  → 浏览器将锚点解析到边界位置（空格之前）        [已观测：空格被吞]
  → 拖选跨越嵌套内联边界（bg span / ul span / 包裹 span）
  → 锚点被吸附/调整到祖先内联盒起点（段首）        [推断，待探针观测]
  → 选区 = 段首 → 光标（大过扩）                  [已观测]
  → mouseup 忠实收藏该大区间                       [已观测]
```

## 三、结论与推测的边界

**【结论（已观测/已实验）】**
1. 触发是**位置条件**（紧邻已收藏词的边界危险区起笔），不是时间条件——M-render 竞态机制证伪；
2. 「空格被吞」在划选过程中实时发生——锚点从划选开始即落在边界，排除 mouseup 时刻机制；
3. H5/H6（硬件/OS）维持排除（换鼠标实验 + 位置相关性）。

**【推测（待直接观测）】**
1. 锚点从「空格前」跳变/吸附到「段首」的具体浏览器行为：候选——(a) 拖动起点方向轻微翻转（手抖先左后右）触发向祖先内联盒起点的吸附；(b) 跨越嵌套内联边界时锚点被调整。二者需探针区分；
2. padding 是危险区的**放大器**（实验 2 旁证），嵌套是危险区的**本体**——各自贡献度待隔离实验定量。

## 四、下一步验证方案（现在可复现，按序执行）

1. **探针（决定性，已具备架设条件）**：`selectionchange` 实时记录锚点节点身份（文本节点路径 / data-bookmark-id）与 offset，复现一次「粘黏→过扩」，确认锚点跳变的**时刻**与**目标节点**：
   - 若锚点在某次 selectionchange 中从边界位置跳到段首 → 吸附机制实锤，可进一步看跳变前焦点是否越过锚点（方向翻转）；
   - 若锚点从 mousedown 起就在段首 → 起笔解析即异常（hit-test 问题），机制图像需改写。
2. **起笔位置对照**：从目标词首字**正中**起笔 ×20 vs 从词前空格边缘起笔 ×20。前者从不发作 + 后者高发 → 危险区假说确认。
3. **结构隔离（借可复现场景重测，结论将比实验 2 可靠）**：
   - 仅去 padding → 粘黏/过扩是否消失；
   - 仅去嵌套（bg span 抽为同级）→ 是否消失；
   - 仅去整段包裹 span → 是否消失。
4. **方向翻转测试**：起笔后故意先左移 2–3px 再右拖 vs 直接右拖，比较发作率（验证推测 1a）。
