# 进度计算简化方案 — 从词数模型到段落模型

- **日期**：2026-06-20
- **关联分析**：[01_问题分析报告.md](01_问题分析报告.md)

---

## 一、简化目标

将进度计算从 **词数比例**（`readWords / totalWords`）改为 **段落比例**（`position / totalParagraphs`）。

---

## 二、改动总览

| 函数 | 当前状态 | 简化后 |
|------|---------|--------|
| `cleanInlineMarkdown` | 5 次正则 replace，用于词数统计 | **删除** |
| `countWords` | split + filter 计数 | **删除** |
| `getWordOffsetAtParagraph` | 含 clamp 防护，105 行 | **删除**（export 移除） |
| `getTotalWords` | wordCount \|\| countWords 回退 | **删除**（export 移除） |
| `calcSingleProgress` | `readWords / totalWords × 100` | `position / totalParagraphs × 100` |
| `calcMultiSectionProgress` | `cumulativeWords / totalWords × 100` | `completedParagraphs / totalParagraphs × 100` |
| `calcProgress` | 含 debug 日志 | 移除日志 |
| `getMarkdownParagraphs` | 内部调用 `cleanInlineMarkdown` | 直接 push 原始文本 |
| `getParagraphs` / `getMarkdownParagraphs` / `isListBlock` | 不变 | 保持不变 |

## 五、有效性评估

| 偏差源 | 之前（词数模型） | 之后（段落模型） |
|--------|---------------|---------------|
| 段落计数不一致（AST vs regex） | 溢出 → 99% | clamp 到有效段落 → 合理值 |
| 词数来源不一致（readWords vs totalWords） | readWords ≠ totalWords → 偏差 | **消除**——不再使用词数 |
| CRLF 换行符 | `\n\n+` 分割失败 → 偏移 | 同左（归一化已修复） |
| 引用块内部段落 | 合并为 1 段 → 偏移 | 同左（bodyFixed 已修复） |
| cleanInlineMarkdown 副作用 | 空字符串 / 异常文本 | **消除**——不再清洗 |
| wordCount 为空导致崩溃 | `undefined.split` 错误 | **消除**——不再使用 |
| 短段落 vs 长段落 | 长段落权重高 | 平等对待（各算 1 段） |
