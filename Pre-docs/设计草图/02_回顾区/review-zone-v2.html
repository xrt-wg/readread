v2 · UX 调整说明

📐 调整 1：移除回顾进行中的统计行
3 张统计卡从进行中页面移除。这些数据是"仪表盘"信息，不需要在每次翻面时看到。改为在完成页面呈现本轮统计。
🎯 调整 2：反馈按钮视觉权重重新分配
熟练 = 实心绿色按钮（primary CTA，带微阴影和 hover 上浮）→ 引导用户向正向反馈倾斜。一般 = 浅琥珀色底（secondary）。生疏 = 红色 outline（tertiary，最低视觉权重）。
📊 调整 3：完成页面增加本轮表现统计
新增「熟练 N / 一般 N / 生疏 N」三列彩色统计，给用户清晰的闭环反馈。
🏷️ 调整 4：背面新增文章来源，移除章节标题
在类型标签旁加入「来自《文章标题》」信息——文章出处是记忆锚点。章节标题信息量低，移除。
🔄 调整 5：CSS 3D 翻面动画
perspective + rotateY(180deg) + backface-visibility，0.5s cubic-bezier。点击卡片即可翻转。
📏 调整 6：进度条加粗 + 计数居中上方
进度条 3px → 5px，金色渐变填充。"1 / 10" 计数居中于进度条上方，替换右侧百分比。
✂️ 调整 7：移除底部翻面按钮
翻转操作统一为点击卡片。底部不再有"看详情/看正面"按钮，减少重复操作入口。
✂️ 调整 8：移除左上角"回顾"标题
标题信息冗余——用户在回顾 tab 中已知道自己所处位置。移除后首屏更干净。
⏭️ 调整 9：移除翻面提示和跳过按钮
卡片底部的"翻转"提示图标和底栏左侧的"跳过"按钮均已移除。翻面操作仅通过点击卡片触发，控制栏仅保留反馈按钮组，更加简洁。
🎨 保持不变的
CSS 变量体系、字体栈（Playfair Display / Lora / DM Sans）、圆角语言、金墨配色、卡片阴影、整体 parchment 氛围。
