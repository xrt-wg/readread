## 七、审核结论

### 7.1 整体评估

| 阶段 | 状态 | 备注 |
|------|------|------|
| Phase 0：类型定义与数据层升级 | ⚠️ 有条件通过 | 两个 createDocument 缺失 `updatedAt` 字段；bookmarkStore 边界兼容性可接受 |
| Phase 1：提取器重构与 EPUB 支持 | ❌ 不通过 | EPUB order 碰撞、sourceUrl 未传播、缺少 explicit scroll-to-top |
| Phase 2：渲染层适配 | ❌ 不通过 | 缺少 section 切换 scroll-to-top；纯文本路径 bookmark 过滤缺陷；BookmarkPanel 跳转无 section 上下文；本地 readingMark 持久化丢失 sectionId |
| Phase 3：下游系统适配 | ⚠️ 有条件通过 | 跳转缺少 section 切换；迁移脚本未更新（但迁移 UI 已停用） |

### 7.2 阻塞项

| 编号 | 问题描述 | 对应审核项 | 严重程度 | 建议修复方案 |
|------|---------|-----------|---------|-------------|
| BLK-01 | EPUB TOC flattenTocTree 中 order 计数器在每个递归调用中重置为 0，导致跨子树 order 值碰撞 | B-004 | 🔴 高 | 将 order 作为外部累加器传入或使用闭包变量：`flattenTocTree(tocItems, depth, {order: 0})` |
| BLK-02 | URL 提取器的 sourceUrl 未传播到 Document | U-001 | 🟡 中 | 在 ExtractionMeta 中增加 `sourceUrl` 字段，urlExtractor 设置，createDocument 读取而非硬编码 `null` |
| BLK-03 | 切换 section 时缺少滚动到顶部的行为 | S-004 | 🟡 中 | 添加 `useEffect` 依赖 `currentSectionIdx`：`window.scrollTo(0, 0)` 或 `contentRef.current?.scrollTo(0, 0)` |
| BLK-04 | 纯文本渲染路径 bookmark 未按 sectionId 过滤 | X-F01 | 🔴 高 | [ReaderPage.jsx:773](src/components/ReaderPage.jsx#L773) 增加 sectionId 过滤条件，与 Markdown 路径保持一致 |
| BLK-05 | BookmarkPanel/ReviewModal 跳转无 section 切换逻辑 | W-002 / X-F02 | 🔴 高 | `handleJump` 增加 section 参数，先 `setCurrentSectionIdx` 再滚动。BookmarkPanel 传递 `sectionId` |
| BLK-06 | 本地 readingMark 持久化丢失 sectionId（页面刷新后 sectionId 为 null） | G-001 / X-F03 | 🟡 中 | `readingMarkStore.save` 接受 `sectionId` 参数，在 `writeJSON` 之前设置 |
| BLK-07 | 两个 createDocument 均缺失 `updatedAt` 字段 | C-006 | 🟢 低 | 补充 `updatedAt: null`（如 `updatedAt: article.updatedAt ?? null`） |
| BLK-08 | handleJumpToReadingMark 使用 setTimeout 100ms 竞态 | G-002 | 🟡 中 | 改用 `useEffect` 监听 `currentSectionIdx` 或 `requestAnimationFrame` 确保 DOM 就绪后再滚动 |
| BLK-09 | 本地/远程迁移脚本未适配新字段 | N-001 | 🟢 低 | 补充所有缺失的字段映射。或明确标记为 deprecated 并添加注释说明当前使用 silentImport 路径 |
| BLK-10 | EPUB DRM 检测无专门逻辑 | B-010 | 🟢 低 | 在 `parse-epub.cjs` 的 catch 中检测常见 DRM 错误关键字，返回友好的中文错误提示 |

### 7.3 已知偏差

| 编号 | 偏差描述 | 原因 | 后续计划 |

| DEV-01 | epub2MD 通过 Netlify Function 代理而非客户端动态 import | epub2MD 依赖 Node.js Buffer/path/fs 等内置模块，浏览器端不可用 | 已确认架构合理，无需变更 |
