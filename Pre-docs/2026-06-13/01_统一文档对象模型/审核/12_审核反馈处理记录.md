## 二、逐项修复详情

### BLK-01: EPUB order 碰撞 (P0)

**问题**：`parse-epub.cjs` 中 `flattenTocTree` 函数在每个递归调用中 `let order = 0`，导致 Chapter 1 的 1.1 (order 0) 与 Chapter 2 的 2.1 (order 0) 碰撞。

**修复**：将 `order` 改为共享累加器对象 `counter = { value: 0 }`，跨递归调用传递。

```diff
-function flattenTocTree(tocItems, depth = 0) {
+function flattenTocTree(tocItems, depth = 0, counter = { value: 0 }) {
   const result = []
-  let order = 0
   for (const item of tocItems) {
     result.push({
-      order: order++,
+      order: counter.value++,
     })
-    if (item.children?.length) result.push(...flattenTocTree(item.children, depth + 1))
+    if (item.children?.length) result.push(...flattenTocTree(item.children, depth + 1, counter))
   }
 }
```

**影响文件**: `netlify/functions/parse-epub.cjs`


### BLK-04: 纯文本路径 bookmark 未按 sectionId 过滤 (P0)

**问题**：`ReaderPage.jsx:773` 纯文本多 section 渲染路径中，`bookmarks.filter(b => b.paragraphIndex === i)` 缺少 sectionId 过滤，不同 section 的同索引 bookmark 会错误跨 section 显示。

**修复**：增加 sectionId 过滤条件。

```diff
- const paraBMs = bookmarks.filter((b) => b.paragraphIndex === i)
+ const paraBMs = bookmarks.filter((b) => b.paragraphIndex === i
+   && (hasMultipleSections ? b.sectionId === (currentSection?.id ?? null) : true))
```

**影响文件**: `src/components/ReaderPage.jsx`


### BLK-05: BookmarkPanel 跳转无 section 切换 (P0)

**问题**：BookmarkPanel 的 `onJump` 只传递 `paragraphIndex`，ReaderPage 的 `handleJump` 在存在重复 paragraphIndex 的多 section 文档中会跳到错误 section。ReviewModal 同理。

**修复**：
1. `handleJump` 增加 `sectionId` 参数，多 section 时先 `setCurrentSectionIdx` 再滚动
2. `BookmarkPanel` 的 `onJump` 同时传递 `paragraphIndex` 和 `sectionId`

**影响文件**: `src/components/ReaderPage.jsx`, `src/components/BookmarkPanel.jsx`


### BLK-02: sourceUrl 未传播 (P1)

**问题**：`urlExtractor` 未将 URL 传入 `meta`，`createDocument` 硬编码 `sourceUrl: null`。

**修复**：
1. `urlExtractor.js` 在 meta 中增加 `sourceUrl: url`
2. `extractors/index.js` 的 `createDocument` 改为 `sourceUrl: result.meta.sourceUrl ?? null`

**影响文件**: `src/services/extractors/urlExtractor.js`, `src/services/extractors/index.js`


### BLK-03: section 切换缺 scroll-to-top (P1)

**问题**：`S-004` 未实现。切换 section 后视口停留在原位置。

**修复**：新增 `useEffect`，在 `hasMultipleSections` 时监听 `currentSectionIdx` 变化 → `window.scrollTo({ top: 0, behavior: 'instant' })`。

**影响文件**: `src/components/ReaderPage.jsx`


### BLK-06: 本地 readingMark 持久化丢失 sectionId (P1)

**问题**：`readingMarkStore.save` 在 `writeJSON` **之后**才通过 `library.js` 向内存对象添加 `sectionId`，页面刷新后 sectionId 为 null。

**修复**：
1. `storage.js` 的 `readingMarkStore.save` 增加 `sectionId` 参数，在 `writeJSON` **之前**设置
2. `library.js` 的本地路径改为 `readingMarkStore.save(articleId, paragraphIndex, sectionId)`，不再事后赋值

**影响文件**: `src/store/storage.js`, `src/services/library.js`


### BLK-08: setTimeout 竞态 (P1)

**问题**：`handleJumpToReadingMark` 使用 `setTimeout(..., 100)` 等待 DOM 就绪后滚动——100ms 不保证 DOM 已渲染。

**修复**：改用 `useEffect` 监听 `currentSectionIdx`。切换 section 时先设置 `pendingScrollRef`，`useEffect` 检测到目标 section 已激活后再延迟 150ms 滚动。同 section 直接滚动。

**影响文件**: `src/components/ReaderPage.jsx`


### BLK-07: createDocument 缺 updatedAt (P2)

**问题**：两个 `createDocument`（storage.js 和 extractors/index.js）均缺少 `updatedAt` 字段。

**修复**：两者均补充 `updatedAt: null`。

**影响文件**: `src/store/storage.js`, `src/services/extractors/index.js`


### BLK-09: 迁移脚本未适配新字段 (P2)

**问题**：`localMigration.js` 和 `remoteMigration.js` 的字段映射缺少 Document 模型全部新字段。

**修复**：补充所有缺失映射（articles: author/format/coverUrl/lang/sourceUrl/sections/sectionCount；bookmarks: sectionId/sectionHeading；readingMarks: sectionId/completedSections），并标注迁移 UI 已停用以 silentImport 替代。

**影响文件**: `src/services/migration/localMigration.js`, `src/services/migration/remoteMigration.js`


### BLK-10: DRM 检测无中文提示 (P2)

**问题**：EPUB 解析失败时，错误消息直接透传 `epub2md` 英文原始错误。

**修复**：在 `parse-epub.cjs` 的 catch 中增加错误分类：
- `drm|encrypt|protected|rights` → "该 EPUB 受 DRM 保护或已加密，无法导入。请使用无 DRM 的 EPUB 文件。"
- `invalid|corrupt|zip` → "该 EPUB 文件已损坏或格式无效，无法解析。"
- 其他 → "EPUB 解析失败，请检查文件是否完整。"

**影响文件**: `netlify/functions/parse-epub.cjs`
