## 说明

1. 每个职员由以下信息来唯一标定：
   - **类别**：Human / Agent
   - **编号**：
     - 人类：`ReadRead-[序号]`（从00开始）
     - Agent：`[小组]-[职位]-Agent-[序号]`（从01开始）
     - 注：人类和Agent分别使用各自的序号列表；编号只能包括字母/短线/数字
   - **代称**：使用3-4个英文字母进行命名（例如：Finn, Iris, Knox）

2. 组织架构说明：
   - 各小组负责人均由产品线负责人 Kaven 兼任
   - 各小组经理由 Agent 担任，负责日常管理和任务协调
   - 各小组工程师/设计师/专员由 Agent 担任，负责具体执行工作
