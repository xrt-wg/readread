## 一、审核说明

### 1.1 审核目标

对照设计文档，逐项验证实施成果是否符合预期，确保：

- `reviewUtils.js` 中的 `computeNextReview()` 调度逻辑正确（首次特殊处理 + delta 公式 + 钳制）
- `isDue()` 判断函数正确（含防御性处理）
- `computeReviewStats()` 统计计算正确（含"尚无数据"场景）
- `listDueBookmarks()` 组卷逻辑正确（到期优先 + 新卡片补足 + 未来兜底 + 本轮排除）
- `ReviewCard.jsx` 正反面视觉与现有一致，反馈按钮可用
- `ReviewPanel.jsx` 重构为容器组件，接入 ReviewCard + reviewUtils
- `ReviewModal.jsx` 最小适配完成（import 切换）
- 统计指标 UI 正确展示（待复习 / 已掌握 / 总收藏）
- 反馈交互正确（保存 → 推进 + 防重复点击 + 闭包安全 + 本轮排除）
- 现有功能无退化（书架 / 阅读 / 收藏 / 导入）

### 1.2 审核方式

| 标记 | 含义 |
|------|------|
| ✅ 通过 | 实施完全符合规范，无遗留问题 |
| ⚠️ 有条件通过 | 实施基本符合规范，存在已知的、可接受的偏差 |
| ❌ 不通过 | 实施与规范存在实质性偏差，需修复后重新审核 |
| — 不适用 | 该项在当前阶段不适用 |

### A.1 调度函数验证

```
1. 浏览器 console：import { computeNextReview } from './utils/reviewUtils'
2. computeNextReview({familiarity:0}, 'hard') → {familiarity:1, nextReviewAt:+1d, reviewCount:1}
3. computeNextReview({familiarity:0}, 'ok')   → {familiarity:2, nextReviewAt:+3d, reviewCount:1}
4. computeNextReview({familiarity:0}, 'easy') → {familiarity:3, nextReviewAt:+7d, reviewCount:1}
5. computeNextReview({familiarity:2, reviewCount:3}, 'hard') → {familiarity:1, nextReviewAt:+1d, reviewCount:4}
6. computeNextReview({familiarity:5, reviewCount:2}, 'easy') → {familiarity:5, nextReviewAt:+30d, reviewCount:3}
7. computeNextReview({familiarity:1, reviewCount:5}, 'hard') → {familiarity:1, nextReviewAt:+1d, reviewCount:6}
```

### A.2 isDue 防御性处理验证

```
8. isDue({reviewCount:0}) → true（从未复习）
9. isDue({reviewCount:1, nextReviewAt:'2026-01-01'}) → true（已到期）
10. isDue({reviewCount:1, nextReviewAt:'2099-01-01'}) → false（未到期）
11. isDue({reviewCount:1, nextReviewAt:null}) → true（防御：异常卡片视为到期）
```

### A.3 统计函数验证

```
12. computeReviewStats([]) → {due:0, mastered:'尚无数据', total:0}
```
