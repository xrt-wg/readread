## 3. 结构与视觉规格

### 3.1 卡片信息架构

```text
类型                          收藏于 9月19日
─────────────────────────────────────────
正文区（全卡唯一内容滚动区）
  词/短语：目标 → [揭示后释义] → 语境 → [揭示后语境译文]
  句/段：原文 → [揭示后参考译文]
下滑继续阅读（仅有未读的溢出内容时显示）
来源：《文章标题》
─────────────────────────────────────────
第 X / N 条       [查看释义 / 查看参考译文]
或：返回原文      [生疏] [模糊] [熟练]
已处理进度及可访问文本
```

来源、按钮、错误信息不覆盖正文。正文保留换行（pre-wrap），英文按正常词边界换行，仅超长不可分词/URL 做 anywhere 兜底；中文自然换行。正文原样展示文本，不引入 HTML 注入或 Markdown 执行。

### 3.2 初始尺寸

- 保持卡片最大宽度 560px；窄屏 width:100%、min-width:0。常规内边距 24px，窄屏 16px。
- 短词标题 28–36px、600 字重、1.25 行高，短释义 20–22px、600；目标与释义均以三行为大字上限，超过后使用 18px 正文排版，不裁切内容。
- 句/段英文 18px、400、1.75，中文 17px、400、1.75；窄屏可统一 16px、1.7。语境 15–16px、1.7；元信息 12px。
- 原文和译文间距 20px，区块标签到正文 8px；来源和操作区使用稳定间距及轻边框。
- 不把字体大小绑定到整个视口 vw；保持现有品牌字体，中文使用可用的系统回退字体。
- 评分按钮等宽等权；实际点击区域至少 44px 高。窄屏操作区换行，评分一行三等分，不横向溢出。
- 普通正文对比度目标至少 4.5:1；辅助文本不能用多层 opacity 降低到不可读。新增颜色令牌同时定义日夜值，沿用项目 CLAUDE.md 颜色规范。

这些数值是首版实现基线；如样本验收要求调整，更新此节而非另加互相冲突的局部覆盖。

### 3.3 高度与滚动契约

卡片 grid 行为 auto / minmax(0, 1fr) / auto / auto，正文层 min-height:0、overflow-y:auto；其余为正常流。卡片初始最小高度约 320px，常规最大高度不超过实际 Hub 可用高度且不超过 680px。不要同时保留多个词条、例句 max-height 滚动容器。

ImportPage 在 tablet 模式本已有 main 滚动，须先测量该容器与页面模式的实际可用内容高度。通过容器高度或 ResizeObserver 向回顾提供可用高度，不写死“100vh 减去猜测的头部高度”。动态尺寸读取放 effect/observer，不放 render。

当可用高度低于 420px，或放大后固定信息与操作已无法给正文留下至少 160px 时，切到自然流模式：解除卡片上限、关闭正文内部滚动，由当前页面/main 滚动，操作随文档可达。不叠加 sticky 遮挡内容。不同模式的滚动归属必须在浏览器验证。

滚动提示根据 scrollHeight > clientHeight 且尚未到末尾计算（容忍约 2px 舍入差）；scroll、ResizeObserver、字体加载和内容变化后更新。提示空间预留，避免提示出现/消失造成布局循环。短类型是否超过三行的测量也放布局阶段，按字体/宽度/文本变更重算，防止大字/小字来回震荡。

### 3.4 揭示与滚动位置

每条新卡初始为原文，滚动置顶。揭示句/段译文后将“参考译文”标签滚入正文可见区，同时保持按钮焦点稳定；返回原文恢复原文面此前的阅读位置。词/短语揭示后优先展示目标释义。

只渲染当前可访问的内容；未揭示答案不能被屏幕阅读器提前读出。按钮有 focus-visible，正文区需要时可聚焦并由键盘滚动。卡片切换通过轻量 live region 宣告位置；不自动朗读整段。评分保存失败使用明确错误提示。

移除整卡 3D 翻面。淡入为纯装饰，减少动画偏好下关闭，不能依赖 transitionend 触发下一张。原文朗读保留，切卡、跳过、刷新替换内容、离开面板时 stop；翻译揭示不自动播放。

## 4. 会话与反馈状态机

建议面板状态：loading、loadError、empty、active、finished；active 内含 revealed、saving、saveError。不要用 cards.length===0 同时推导加载、失败和空数据。

| 事件 | 处理 |
| --- | --- |
| 打开/账号变化 | 开启新请求代次，加载队列；旧请求结果不能覆盖新会话 |
| 揭示有效答案 | revealed=true，允许评分；只是查看，不写记录 |
| 评分 | 同步 ref 锁 + UI saving；保存本次 cardId、会话代次、评分和计算结果；禁止再次评分、回翻与跳过 |
| 保存成功 | 校验仍是当前代次，按 cardId 只提交一次本地统计；加入 handledIds；随后推进或结束 |
| 保存失败 | 解锁并留在当前已揭示卡；保留滚动；显示“保存失败，请重试”；不增进度、不增统计 |
| 重试同一评分 | 复用该次计算的 reviewCount/familiarity/nextReviewAt patch，避免响应丢失后的重试再次累计 |
| 刷新异常卡 | 按 ID 重读，刷新中锁该操作；成功替换内容并恢复原文面；失败保留原内容及提示 |
| 暂时跳过异常卡 | 不请求评分保存；加入 handledIds 和 skippedIds；处理进度+1，评分统计不变 |
| 再来一轮 | 使用连续会话 handledIds 排除；每轮位置/统计重置，handledIds 保留到离开面板或账号变化 |
| 卸载/账号变化 | 停止朗读，使旧结果失效；已发出的服务端写入不宣称可以撤回 |

当前 handleSlideExit / handleSlideEnter 业务推进链应移除。简单串行流程优先，不引入状态机依赖。保存完成后即使动画关闭或事件丢失，也必须恰好推进一次。

进度定义：processed=成功评分数+跳过数，进度=processed/本轮初始数量。位置为当前 index+1。结束时展示“已回顾 A 条，跳过 B 条”及仅成功保存的三类统计；不能再使用 cards.length 作为已回顾数。

## 5. 数据写入与异常内容

### 5.1 字段隔离

回顾专用服务只允许写 `review_count`、`familiarity`、`next_review_at`；翻译专用服务只允许写 `translation`、`context_translation`、`translation_provider`、`translation_status`。沿用既有 updated_at 维护机制。云端使用 update，限定 bookmark ID、当前 user_id、deleted_at IS NULL，并读取返回结果；零行更新视为失败，绝不 upsert 重建或把 deleted_at 设为 null。

翻译失败时仅改状态，不把未成功生成的空结果写成成功译文；继续保持原回退顺序，不新增模型请求。useBookmarkAI 回调收到实际保存结果，不能返回拼装的过期整条对象。

本地分支在提交时读取当前 bookmark，以白名单字段合并，目标不存在报错；不可用旧快照覆盖现有语境、翻译或复习值。本地不新增 updatedAt 维护，保留已有值；继续通过 writeJSON 写 localStorage，不新增自定义 storage 事件。先持久化成功再替换内存缓存，避免存储失败污染缓存。云端继续依赖数据库 updated_at 触发器。创建收藏、导入等原有整对象保存路径不在此次全面重构范围。

此方式防止当前回顾与异步翻译互相覆盖，但不能保证不同设备同时评分的原子累加。若需要服务端幂等事件账本，应另立任务，不把本次前端锁描述为完整并发协议。

### 5.2 异常卡判定

先做空白字符串归一化，再判断：

1. 原文为空：显示“这条收藏暂无原文”，禁用朗读和评分，允许刷新/暂时跳过。
2. translationStatus=pending：显示“译文尚未就绪”，不声称当前页面正在生成；刷新只读取。
3. translationStatus=error：显示“译文生成失败”，允许刷新/暂时跳过，不自动重试生成。
4. done 但译文为空：显示“暂无可核对的译文”，按异常处理。
5. 未知/缺失历史状态：主译文非空允许核对；主译文为空显示“暂无可核对的译文”，允许刷新/暂时跳过，不评分、不自动生成。主译文有效而仅 contextTranslation 缺失不阻塞评分。该兜底不以线上存在 NULL 状态为前提，仓库云端列有 NOT NULL 约束。

刷新发现已删除或无权限，展示对应错误，不能恢复收藏。普通卡无通用跳过按钮；异常跳过不增加 reviewCount。

### 5.3 空态与错误文案

- 加载：正在加载回顾内容；不显示零收藏引导。
- 加载失败：加载失败，请重试；提供重试，不展示空态。
- 空队列时追加一次收藏查询区分：确无收藏才显示“阅读时划选并收藏，即可在这里回顾”。
- 有收藏但队列为空：本次没有更多可回顾内容；不说“全部到期已完成”。
- 追加查询失败：降级中性提示并允许重试，不能假定没有收藏。

## 7. 验收矩阵

| 类别 | 必须通过 |
| --- | --- |
| 短内容 | 单词、短语、短句：无不必要滚动；释义清楚；大字没有挤压语境 |
| 长内容 | 截图同类段落、双倍长度段落、长释义、超长短语、长语境：全文可达、仅一个正文滚动区、无横向溢出 |
| 元数据 | 超长中英文标题、无标题、无效日期：不盖正文、不挤掉评分；完整标题可用键盘展开 |
| 响应式 | 1440×900、1024×768、390×844、320×568、844×390；覆盖 Hub tablet 与非 tablet 布局；200% 缩放时可读可操作 |
| 主题与输入 | 日间/夜间、键盘、鼠标选择复制、触摸滚动：不会意外揭示或评分；焦点可见；对比度达到目标 |
| 答案与朗读 | 正面不能评分或通过辅助技术读到答案；揭示定位合理；切卡和离开后无残留朗读 |
| 长文本提示 | 仅实际溢出且未到底时出现；到底消失；字体/宽度变化更新；提示不遮文字、不制造尺寸振荡 |
| 保存 | 延迟 3 秒、失败后重试、快速连点：成功前不推进，失败不计数，同次最多一次本地推进 |
| 生命周期 | 保存中切换 Tab/账号：旧结果不污染新面板；关闭动画及减少动画模式照常推进 |
| 写入隔离 | 翻译先结束/后结束、回顾先结束/后结束：两组字段均保留；删除后不能被迟到写入复活 |
| 异常内容 | pending、error、done+空译文、空原文、仅缺语境译文：展示/禁用/刷新/跳过符合规则 |
| 进度 | 第一张 0/N；最后一张未处理不满格；跳过独立计数；全部跳过不显示成功回顾 N 条 |
| 连续会话 | 再来一轮不会重复本次已评分/跳过 ID；空队列文案不声称清空全库 |
| 回归 | 原调度公式、收藏创建与阅读翻译回调正常；其他 Tab 布局无变化；旧 Modal 不出现接口异常 |

自动化侧重点是状态和数据完整性，不写只检查某个 CSS 常量存在的测试。项目当前没有统一 test/lint npm 脚本；新增脚本明确执行命令，不能报告不存在的 npm test/lint 已通过。构建不能替代浏览器视觉验收。

## 8. 风险、退出条件与回滚

- 实际 Hub 高度可能与视口高度不同：必须验证两种页面布局；无法保留合理正文高度时使用自然流兜底。
- 去除 3D 翻面会改变熟悉感：通过清楚的揭示按钮、稳定来源/操作位置和温和的切卡反馈维持识别，不用动画补偿不明确的操作。
- 字段 patch 扩展了服务层范围：以交错写入和删除目标测试作为必要验收；不得只验收视觉后发布。
- 生产 RPC 版本未知：本次不迁移队列，不以仓库 SQL 推断线上实际返回顺序。记录不足量问题，不在实施中顺手改调度。
- 对请求结果不确定的网络故障，客户端重试复用 patch 只能降低重复累计风险，不提供全局幂等保证。

完成条件为上述矩阵通过且无未解释的布局/保存失败；任何未验证环境明确写入实施记录，不泛称全平台通过。拆成字段隔离、交互状态、视觉布局三个可审查提交为宜，避免纳入原有未提交内容。无 schema 迁移，回滚仅回退本次相关提交；已保存的复习数据不回写、不清空。
