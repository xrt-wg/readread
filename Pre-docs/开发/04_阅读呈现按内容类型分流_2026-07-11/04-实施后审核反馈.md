## 二、关键实现点逐项审核

### 2.1 `groupIntoChapters`（ReaderPage.jsx:35-47）

**方案要求**：按 `depth===0` 划界，子节归入其顶层章。

**实际代码**：
```js
function groupIntoChapters(sections) {
  const chapters = []
  for (const section of sections) {
    if (section.depth === 0 || chapters.length === 0) {
      chapters.push({ lead: section, all: [section], wordCount: section.body.wordCount, order: chapters.length })
    } else {
      const cur = chapters[chapters.length - 1]
      cur.all.push(section)
      cur.wordCount += section.body.wordCount
    }
  }
  return chapters
}
```

**边界分析**：

| 输入场景 | 输出 | 判定 |
|---------|------|------|
| 无序言 + 2 个 `##` 章 + 若干 `###` 子节 | 2 个 chapter，子节归入对应章 | ✅ |
| 有序言（heading=null, depth=0）+ `##` 章 | 序言独立成 chapter[0]，后续 `##` 各成一章 | ✅ |
| 纯序言 + 无 heading 的 section | 1 个 chapter | ✅ |
| 空 sections | 0 个 chapter → `paginated=false`（安全降级） | ✅ |
| 首个 section depth>0（异常数据） | 自成一章（`chapters.length===0` 触发） | ✅ 防御性处理 |
| 全 depth>0（无顶层） | 全部归入 1 个 chapter | ✅ 防御性处理 |

**审核结论**：✅ 算法正确，边界处理稳健。额外包含了首个 section 非 depth=0 的防御。

### 2.6 进度计算（ReaderPage.jsx:330-337, 352）

**方案要求**：article 用 `scrollPercent`；book 用章加权计算。

**实际**：
```js
// L352:
const rawPercent = paginated ? calcBookProgressAtMark(scrollPercent) : scrollPercent

// L330-337:
function calcBookProgressAtMark(scrollPercent) {
  const totalWords = chapters.reduce((sum, ch) => sum + ch.wordCount, 0)
  if (totalWords === 0) return scrollPercent
  let cumulative = 0
  for (let i = 0; i < currentChapterIdx; i++) cumulative += chapters[i].wordCount
  cumulative += (chapters[currentChapterIdx]?.wordCount ?? 0) * (scrollPercent / 100)
  return Math.round((cumulative / totalWords) * 100)
}
```

**审核**：
- article：`scrollPercent` 直接来自整页滚动位置 → 与旧单节行为一致 ✅
- book：已完成章全词数 + 当前章加权 → 语义正确 ✅
- `totalWords === 0` 守卫 → 防御空内容 ✅
- `chapters[currentChapterIdx]?.wordCount ?? 0` → 防御越界 ✅
