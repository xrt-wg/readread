## Step 2 — 新建 Netlify Function

**目标**：创建专用的推荐生成 API endpoint，含完整的输入校验、provider 故障转移、JSON 解析容错。

**产出物**：
- `netlify/functions/generate-recommendation.js`
- API endpoint: `POST /.netlify/functions/generate-recommendation`
- Request/Response schema（见实施方案 §4.2）

**文件**：
- `netlify/functions/generate-recommendation.js` — 新建

**改动要点**：
1. 导入共享适配器：`const { callGemini, callDeepSeek, ... } = require('./lib/aiProviders')`
2. 导入配置：`const recConfig = require('../../config/recommendation.json')`
3. 导入 presetModels：`const presetModels = require('../../config/presetModels.json')`
4. 实现核心逻辑（见实施方案 §4.3）：
   - 解析 request body
   - 输入大小校验（100K 字符上限 → 413）
   - 构造 Prompt（含 kind 区分逻辑）
   - 获取 API key（优先推荐专用 key → 回退翻译通用 key）
   - 调用 AI API（通过共享适配器）
   - JSON 解析 + 重试（同 provider 1 次）
   - 失败切换 fallbackPreset（1 次）
   - 返回结构化结果 + perf（含 inputTokens / outputTokens）
5. 性能日志格式与 `translate.js` 保持一致

**验收标准**：
- `POST` 请求返回合法的 `{ result: {...}, perf: {...} }` JSON
- 含完整 articleText 时返回非空字段
- articleText 为空时返回 400
- articleText > 100K 字符时返回 413
- AI API 不可达时：同 provider 重试 → 切换 fallback → 仍失败返回 500
- 可在 Netlify Dev 本地环境调试

## Step 5 — submitRecommendation 服务扩展

**目标**：支持基本属性覆盖 + 先回写后提交的事务顺序。

**产出物**：`submitRecommendation()` 接口扩展，含事务保护逻辑。

**文件**：
- `src/services/supabase/recommendationService.js` — 修改

**改动要点**：
1. `submitRecommendation` 参数新增可选字段：
   - `title` — 覆盖默认值
   - `author` — 覆盖默认值
   - `sourceUrl` — 覆盖默认值
   - `kind` — 仅用于回写 import_items
2. 事务顺序：**先 updateImportItem() 再 INSERT INTO recommendation_submissions**：
   ```
   检测属性变更 → 有变更 → updateImportItem()
                              ├── 失败 → throw, 终止
                              └── 成功 → 继续
                   → 无变更 → 继续
   →
   读取 import_item.title/author/source_url
   使用覆盖值（如有）或原始值构造 submission
   INSERT INTO recommendation_submissions
   ```
3. 属性变更检测逻辑：
   ```js
   const attrChanges = {}
   if (title && title !== item.title) attrChanges.title = title
   if (author !== undefined && author !== item.author) attrChanges.author = author
   if (sourceUrl !== undefined && sourceUrl !== item.sourceUrl) attrChanges.source_url = sourceUrl
   if (kind && kind !== item.kind) attrChanges.kind = kind
   ```

**验收标准**：
- 传入覆盖 title → recommendation_submissions 使用覆盖值
- 属性有变更 → import_items 先于推荐记录更新
- updateImportItem 失败 → 推荐记录不创建，错误抛出
- 属性无变更 → 不调用 updateImportItem，直接提交
- 不传覆盖值 → 行为与当前一致（使用 import_item 原始值）
