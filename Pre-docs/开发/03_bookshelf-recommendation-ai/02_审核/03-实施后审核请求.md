## 一、审核目的

在代码实施完成后，对照设计文档逐项验证实现的正确性、完整性和一致性，确保：

1. 所有设计决策被正确执行
2. 所有阻塞项修复已落地
3. 异常路径和降级逻辑正常工作
4. 无实施过程中引入的设计偏离

---

## 二、审核范围

| 层面 | 涉及文件 | 审核重点 |
|------|---------|---------|
| 配置 | `config/recommendation.json`, `config/presetModels.json`, `netlify.toml` | JSON 格式正确性、preset 条目完整、超时配置 |
| Provider 共享层 | `netlify/lib/aiProviders.js`, `netlify/functions/translate.js` | 函数签名正确、translate.js 行为不变 |
| Netlify Function | `netlify/functions/generate-recommendation.js` | 输入校验、故障转移、JSON 解析容错、perf 日志 |
| 前端 AI 服务层 | `src/services/aiProviders/recommendation.js`, `index.js` | 接口签名、AbortSignal 传递、错误类型 |
| 弹窗 UI | `src/components/SubmitRecommendationModal.jsx` | State 统一、缓存提升、降级 UI、双语编辑交互 |
| 父组件 | `src/components/ImportPage.jsx` | 缓存 state 管理、props 传递 |
| 提交服务 | `src/services/supabase/recommendationService.js` | 接口扩展、事务顺序、属性回写 |
