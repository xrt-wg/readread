## 二、逐条处理记录

### P2-1　时区由 `SET LOCAL` 改为函数级 `SET timezone` —— 采纳

- **原反馈**：函数体 `SET LOCAL timezone` 依赖事务块上下文，建议改为函数级 `SET timezone` 子句。
- **独立评估**：**采纳修正方向**。对反馈给出的「autocommit 直接 `select admin_get_growth_stats(...)` 会报 `SET LOCAL can only be used in transaction blocks`」这一具体触发场景持保留——PostgreSQL 顶层 `SELECT func()` 运行在隐式事务内，`SET LOCAL` 通常不会触发该报错。但函数级 `SET timezone` 因三点而**严格更优**，故采纳：① 作用域为函数（进入生效、退出自动恢复），不依赖调用方事务上下文；② `SET LOCAL` 的作用域实为「事务」而非「函数」，若将来被包进更大显式事务调用会泄漏到后续语句；③ 与库内既有 `SET search_path = public` 惯例一致。
- **处理动作**：
  1. 迁移函数头 `SET search_path = public` 后新增 `SET timezone = 'Asia/Shanghai'`（:26），删除函数体 `SET LOCAL timezone TO 'Asia/Shanghai';`。
  2. 同步表述：`01` §2.4 #5 / §四 / §五.4、`02` §二 / §3.1（含内嵌 SQL 片段与关键点）/ §六、`04` §〇.1 / §四.4，统一为「函数级 `SET timezone = 'Asia/Shanghai'`」。
- **验证**：grep 迁移 + 01/02/04 无 `SET LOCAL` / `set local` 残留（仅 03/05 反馈原文保留历史引用，不修改）。

### P3-1　02 §3.1 SQL 片段事务关键字大小写漂移 —— 采纳

- **验证**：grep 02 无 `BEGIN;`/`COMMIT;`/`NOTIFY pgrst` 大写残留。

### P3-2　TrendChart 文字横向拉伸 —— 采纳（采用测宽像素渲染方案）

- **原反馈**：`preserveAspectRatio="none"` 非等比缩放，容器宽 ≠ 720px 时 y 轴刻度/x 轴标签/折线被横向拉伸。
- **独立评估**：**属实**。反馈建议的两个方案（`xMidYMid meet` 接受留白 / 抽离文本层）中，`meet` 会左右留白且需连带修正 hover 的 `ratio` 映射，抽离文本层改动更大；故采用**第三种更干净方案**：ResizeObserver 测量容器实际宽度、按像素直接渲染（去掉 `viewBox` 非等比缩放）。
- **处理动作**：`GrowthStatsPanel.jsx` 的 `TrendChart` 改为 `useRef` + `useState(width)` + `ResizeObserver` 测宽；SVG 由 `viewBox` 改为 `width/height` 像素属性；`innerWidth` / 网格线 `x2` / hover 映射 / tooltip `left` 全部改以实测像素计算。文字不再拉伸、hover 坐标映射随之精确。
- **验证**：`npm run build` 通过；grep 组件无 `CHART_WIDTH`/`viewBox`/`preserveAspectRatio` 残留。

### P3-3　「迁移未到位 → 错误态而非空态」措辞 —— 采纳

- **原反馈**：02 §六 称「迁移未到位降级空态」，实际 RPC 未部署（404）走错误态，仅「RPC 存在但返回空数据」走空态。
- **独立评估**：**属实**，系措辞不精确。
- **处理动作**：`02` §六 澄清为「RPC 返回字段缺失（空数据）→ 空态；RPC 未部署（404）→ 错误态」；`01` §五.5 同步修正。
- **验证**：01/02 已更新。
