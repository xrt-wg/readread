## 附录 B：全链路数据流追踪

```
[写入] 用户滚动页面
  → handleScroll: scrollPercentRef.current = Math.round(window.scrollY / scrollable * 100)
[写入] 用户点击段落标记
  → handleSetReadingMark(paraIndex)
    → scrollPercent = scrollPercentRef.current
    → progressPercent = hasMultipleSections
        ? calcMultiSectionProgressAtMark(article, currentSection, scrollPercent, readingMark)
        : scrollPercent
    → saveReadingMark(articleId, paraIndex, options, sectionId, progressPercent)
      → [云端] fetchCloudReadingMarkRow → merge → upsert(progress_percent)
      → [本地] readingMarkStore.save(articleId, paraIndex, sectionId, progressPercent)
[读取] 列表加载
  → listReadingMarks → readingMarks[articleId]
    → mark.progressPercent (由 mapReadingMarkRow 映射)
[展示] ImportPage
  → progress = mark?.progressPercent ?? null
  → 排序: progressA ?? 0 比较
```
