## 三、轻微问题

### M1：§4.2 调用处未同步 C1 修复

实施方案 §4.2（L185）的 diff 块中仍显示 3 参数调用：

```
? calcMultiSectionProgressAtMark(article, currentSection, scrollPercent)
```

而 §4.3（L227）给出了正确的 4 参数版本：

```
? calcMultiSectionProgressAtMark(article, currentSection, scrollPercent, readingMark)
```

**影响**：§4.2 是主干流程展示，§4.3 是细节补充。开发者阅读到 §4.3 时会看到正确签名。如果只看 §4.2 就开始编码，可能遗漏第 4 参数。建议将 §4.2 的调用处同步为 4 参数版本，或在 §4.2 末尾加注「完整签名见 §4.3」。

**不阻塞**——两份方案均正确，仅存在冗余信息不一致。
