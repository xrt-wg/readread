## 三、重点核验问题清单

1. **RPC 权限**：是否 `revoke from public/anon` + `set search_path = public` + 函数体内 `is_current_user_admin()` 守卫；返回仅展示用、不当作身份信任源。
2. **口径同源**：周滚动是否与 `get_subscription_status` 一致（`v_cur_week` 取 Asia/Shanghai 周一 0 点）；Pro 是否 `importRemaining/bookmarkRemaining` 返回 null；新用户无 `subscriptions`/`user_quotas` 行是否经 LEFT JOIN + `coalesce` 兜底不丢。
3. **时区**：`formatDateOnly` 是否定死 Asia/Shanghai；`pro_expires_at`（timestamptz）转「仅日期」是否无跨日偏差。
4. **静默降级**：后台订阅 RPC 未就绪 / 权限异常时，是否降级为「仅基础信息」、不阻断列表、不误导（`subscription` 缺省走「订阅 —」）。
5. **前端 merge**：`subscriptionByUser` 按 userId 匹配，`profile.userId` 与 RPC `userId` 类型一致（均为字符串 uuid）；无订阅行的用户不丢。
6. **结构重构**：卡片「订阅」字段是否徽标与详情成一体、右上角仅保留账号状态徽标（Free/Pro 不再悬浮头部）。
