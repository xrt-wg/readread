## 四、审核重点（请审核者优先复核，按风险排序）

1. **迁移 SQL 显式列清单（B1 落地）**：`b.status, b.archived_at` 插入位置（`b.deleted_at` 之后、`r.title` 之前）、RETURNS TABLE 补列、5 个 WHERE（2 COUNT + 3 子查询）全带 `status='active'`、两个 COUNT 子查询调度字段全限定 `b.`（防输出变量名歧义）、无回退 `b.*` 写法。
2. **`saveBookmark` upsert 显式带 `status`/`archived_at`**（验收 #10 根因点；漏写 = 任何反馈/翻译保存都重置归档）。
3. **双路径对称**：云端 `setBookmarkStatus`（RLS `bookmarks_update_own` 匹配、`.eq('user_id')`、`.is('deleted_at', null)`）与本地 `bookmarkStore.save` 行为一致。
4. **统计口径并存**：管理区 active 口径 vs 首页/书架含归档口径，是否符合 D5/B3 决策，UI 文案是否区分、不混淆。
5. **本地模式 `articleTitle` 补齐（B4）**与渲染兜底（缺失隐藏来源行）。
6. **`handleArchive` 三点（B7）**：`saving` 入口锁、`isLibraryAccessError → refreshAuthState` 降级、成功后 `reviewedThisSession.add` 防本轮重复。
