# 阅读区与书架区数据模型统一 — 决策记录

> 日期：2026-07-11
> 状态：已确认

---

## 一、核心架构决策

### C1 · 统一为单内容模型

合并 `import_items` 和 `articles` 为一张表 `readings`。用 `reading_status` 字段的枚举转换表达书籍在不同情景间的流转，消除深拷贝、级联维护和数据冗余。

### C2 · 情景视图而非数据隔离

书架区和阅读区是对同一数据的不同情景视图：
- 书架区 = `WHERE reading_status != 'reading'`
- 阅读区 = `WHERE reading_status = 'reading'`

### C3 · 阅读数据跟着书走

bookmarks 和 reading_marks 的 FK 指向 `readings.id`，不指向某次阅读会话。书籍在书架和阅读区之间来回流转时，阅读数据不受影响。

### C4 · 状态字段设计

`reading_status` 四个枚举值：`unread` | `reading` | `in_progress` | `completed`

| 状态 | 含义 | 位置 |
|---|---|---|
| `unread` | 未读过 | 书架 |
| `reading` | 正在读 | 阅读区 |
| `in_progress` | 读过但未读完 | 书架 |
| `completed` | 已读完 | 书架 |

不设独立的 `location` 字段——`location` 由 `reading_status` 唯一派生。

### C5 · 状态流转规则

```
unread     → reading     取书阅读
reading    → completed   标记读完（自动放回书架）
reading    → in_progress 中途放回（显式按钮）
in_progress → reading    继续阅读
completed  → reading     继续阅读
任意状态   → unread      重新阅读（清除所有阅读数据）
```

## 二、功能决策

### D1 · 阅读区书籍上限

**决策**：N 本，暂定 N=5。

**说明**：作为可配置项，后续可随时调整。

### D2 · 还书触发方式

**决策**：两者都有。

- 用户标记读完后**自动放回书架**
- 阅读器提供**显式「放回书架」按钮**（用于中途放弃）

### D3 · 重新阅读入口

**决策**：书架上的独立操作，无需先取书进入阅读区。

点击「重新阅读」后：
1. 清除该书所有 bookmarks
2. 重置 reading_mark
3. reading_status → `unread`

### D4 · 书架区分组

**决策**：采用 Tab 分组（unread / in_progress / completed）。

**说明**：后续可优化为折叠分组等更灵活的展示方式。三种状态的信息层级不对称——unread 侧重预览、in_progress 侧重进度定位、completed 侧重回顾唤起。

### D5 · 表名

**决策**：`readings`（阅读内容）。

**说明**：`books` 与 `kind = 'book'` 语义冲突。`readings` 准确表达「一个用户要阅读的东西」，不论是文章还是电子书。

### D6 · 数据迁移策略

**决策**：以 import_items 为主体，分四步迁移。

1. 以 `import_items` 为主体创建 `readings` 行，reading_status 暂设 `unread`
2. 合并有关联 article 的数据——取最新 article 的状态推断 reading_status，bookmarks 和 reading_marks 的 FK 更新为 readings.id
3. 处理无 source_import_id 的独立 article（旧版 `art_` 前缀数据），作为独立行迁移
4. reading_marks 去重——同一本书多条旧 article 的记录保留最新一条（按 updated_at）

**数据权威性**：sections 以 import_items 为准。

### D7 · 编辑策略

**决策**：分情景处理。

| 当前 reading_status | 编辑行为 | 说明 |
|---|---|---|
| `unread` | 直接编辑 | 无阅读数据需要保护 |
| `reading` | **禁止编辑** | 入口置灰，提示「请先放回书架」 |
| `in_progress` | 元数据直接编辑；内容编辑做影响提示后执行 | 提示：「此操作可能影响阅读进度和书签位置」 |
| `completed` | 同 in_progress | 同 in_progress |

**补充**：「创建副本并编辑」作为书架上的独立操作（类似 D3 的「重新阅读」），不作为编辑的默认路径。

### D8 · origin 枚举值 `manual`

**决策**：在原有 4 个枚举值（`imported` / `shared` / `featured` / `featured_legacy`）基础上新增 `manual`。

**语义**：`manual` 表示旧版遗留数据——在 import_items 表引入之前，用户直接通过 paste/URL 等方式导入到 articles 表的阅读内容。这些内容没有对应的 import_items 来源记录（`source_import_id IS NULL`），也不属于推荐系统或分享体系。合并后统一标记为 `origin = 'manual'` 以区分来源。

## 三、统一数据模型

### `readings` 表结构

```
readings
  ├── id                          text PK
  ├── user_id                     uuid FK profiles
  ├── title                       text NOT NULL
  ├── author                      text
  ├── format                      text NOT NULL   (url|epub|pdf|paste|markdown|html)
  ├── cover_url                   text
  ├── lang                        text            (default 'auto')
  ├── source_url                  text
  ├── sections                    jsonb
  ├── total_word_count            integer
  ├── section_count               integer
  ├── kind                        text            (article|book)
  ├── reading_status              text NOT NULL   (unread|reading|in_progress|completed)
  ├── reading_started_at          timestamptz
  ├── reading_finished_at         timestamptz
  ├── origin                      text            (imported|shared|featured|featured_legacy|manual)
  ├── share_status                text            (private|shared|public)
  ├── share_source_id             text            → recommendation_submissions.id
  ├── created_at                  timestamptz
  ├── updated_at                  timestamptz
  └── deleted_at                  timestamptz
```

### `bookmarks` 表结构（FK 调整）

```
bookmarks
  ├── id                          text PK
  ├── user_id                     uuid FK profiles
  ├── reading_id                  text FK readings    ← 原 article_id
  ├── type                        text
  ├── text                        text
  ├── translation                 text
  ├── translation_provider        text
  ├── translation_status          text
  ├── context_sentence            text
  ├── context_translation         text
  ├── paragraph_index             integer
  ├── char_offset                 integer
  ├── section_id                  text
  ├── section_heading             text
  ├── review_count                integer
  ├── familiarity                 smallint
  ├── next_review_at              timestamptz
  ├── created_at / updated_at / deleted_at
```

### `reading_marks` 表结构（FK 调整）

```
reading_marks
  ├── user_id                     uuid FK profiles   (复合 PK)
  ├── reading_id                  text FK readings    ← 原 article_id (复合 PK)
  ├── paragraph_index             integer
  ├── completed                   boolean
  ├── section_id                  text
  ├── completed_sections          text[]
  ├── progress_percent            integer
  ├── created_at / updated_at
```

### 实体关系

```
profiles
  └── readings (1:N)
        ├── bookmarks (1:N)
        └── reading_marks (1:1 per user+reading)
```
