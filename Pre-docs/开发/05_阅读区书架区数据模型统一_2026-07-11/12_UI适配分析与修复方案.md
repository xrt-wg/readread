> 日期：2026-07-12
> 问题来源：端到端验证发现

## 一、问题分析

### 问题 1：书架区缺少三个子 Tab

**现象**：书架区展示全量导入内容，无法按阅读状态分组查看。

**根因**：D4 决策要求书架区用 Tab 分组（unread / in_progress / completed），但 Phase 3 组件重构时只更新了数据流（服务调用、状态管理），UI 渲染层未同步实现。

**代码位置**：[ImportPage.jsx:536-610](src/components/ImportPage.jsx#L536-L610)——`importItems` 全量传给 `ImportItemList`，无状态筛选：

```
书架区渲染:
  ImportItemList items={importItems}   ← 全量，未按 readingStatus 过滤
```

**数据基础**：每个 `importItems` 条目已有 `readingStatus` 字段（ImportItemList 中 status 标签渲染正常），筛选所需数据已就绪。

### 问题 2：阅读区有删除按钮，应为「放回书架」

**现象**：阅读 Tab 的每个条目卡片上有删除按钮（Trash2 图标）。

**根因**：阅读 Tab 卡片渲染用的是旧 `articles` 表时代的设计，未随数据模型统一而更新。

**代码位置**：[ImportPage.jsx:678](src/components/ImportPage.jsx#L678)：

```jsx
<button onClick={(e) => handleDelete(e, art.id)} ...>
  <Trash2 size={13} />
</button>
```

`handleDelete`（行 281）调用 `deleteArticle` → `deleteReading`，会软删除阅读内容和关联数据。

**设计矛盾**：
- 阅读区的设计初衷是「不受打扰地阅读」，管理动作（删除）不属于此情景
- 按照决策记录 D2：未读完的书应通过「放回书架」归还（status → in_progress），已读完的通过标记完成自动归还（status → completed）
- `handleReturnToShelf` 已在 ReaderPage 中实现，ImportPage 阅读 Tab 未使用

**已有基础设施**：`returnToShelf` 函数已存在于 readings.js，签名如下：
```js
returnToShelf(readingId, { completed: false, canUseCloudLibrary, userId })
```

## 二、修复方案

### 2.1 书架区三 Tab

**改动文件**：`ImportPage.jsx`（shelf 视图区域）+ `ImportItemList.jsx`（可选 props 调整）

**实现方式**：

在书架视图中新增 Tab 栏，筛选逻辑：

```
书架 Tab 栏:  [全部] [未读] [未读完] [已读完]
                    ↓
筛选 importItems:
  'all'         → importItems（全量，保持向后兼容）
  'unread'      → importItems.filter(i => i.readingStatus === 'unread')
  'in_progress' → importItems.filter(i => i.readingStatus === 'in_progress')
  'completed'   → importItems.filter(i => i.readingStatus === 'completed')
```

Tab 栏样式对齐现有设计（参见推荐 Tab 的 tab 栏风格）。

**范围**：
- 新增 `shelfTab` 状态（默认 `'all'`）
- 在 ImportItemList 之前渲染 Tab 栏
- 传给 ImportItemList 的 `items` 按 shelfTab 过滤
- 每个 Tab 显示对应数量（如「未读 (3)」）

### 2.2 阅读区：删除按钮 → 放回书架按钮

**改动文件**：`ImportPage.jsx`（阅读 Tab 卡片渲染）

**实现方式**：

阅读 Tab 卡片（行 668-684）中的按钮区改为分情景渲染：

```
readingZoneItems 中每个 item：
  ├── 该 item 是「正在阅读」状态
  │     └── [放回书架] 按钮 → handleReturnToShelfFromList(item)
  │         调用 returnToShelf(item.id, { completed: false, ... })
  │         刷新 loadLibraryState + loadReadingZone
  │
  └── 已完成标记（completed）
        └── 仅展示标签，无操作按钮
```

`handleReturnToShelfFromList` 逻辑：
```js
const handleReturnToShelfFromList = async (reading) => {
  await returnToShelf(reading.id, { completed: false, canUseCloudLibrary, userId })
  await loadLibraryState()
  await loadReadingZone()
}
```

**注意**：`returnToShelf` 的 `completed: false` 表示未读完放回。如果用户想标记完成，应通过 ReaderPage 内阅读到底点击「标记已读完」自动触发 `returnToShelf(..., completed: true)`——这与 D2 决策一致。

### 2.3 补充：阅读 Tab 空书架时的 ImportPanel

当前 `readingZoneItems.length === 0` 显示的是品牌首页（「读你想读，学你所读」），这在阅读 Tab 的空状态下合理——鼓励用户去书架取书。不需要修改。
