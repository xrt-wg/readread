## 十、数据完整性

| # | 检查项 | 方法 | 结果 |
|---|---|---|---|
| A1 | old articles 表的行数 | Supabase SQL: `SELECT COUNT(*) FROM articles WHERE deleted_at IS NULL` | |
| A2 | readings 表的行数和状态分布 | Supabase SQL: `SELECT reading_status, COUNT(*) FROM readings WHERE deleted_at IS NULL GROUP BY reading_status` | |
| A3 | bookmarks 全部有效 | Supabase SQL: `SELECT COUNT(*) FROM bookmarks b LEFT JOIN readings r ON b.article_id = r.id AND b.user_id = r.user_id WHERE b.deleted_at IS NULL AND r.id IS NULL`（应为 0） | |
| A4 | reading_marks 全部有效 | 同上，检查无孤立的 reading_mark | |
