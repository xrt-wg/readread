# 阅读区与书架区数据模型统一 — 实施方案

> 日期：2026-07-11

## 一、总体策略

### 1.1 核心原则

**一次 migration，渐进式代码重构**

- 数据库变更通过单个新 migration 文件完成，保证原子性
- 代码按「后端→前端」的顺序分层重构，每一层独立可验证
- 每一步都有明确的验证标准和回滚路径

### 1.2 实施顺序

```
Phase 1: 数据库 migration → 新 readings 表建立，数据迁移，旧表保留
Phase 2: 服务层重构 → readings 表 CRUD，消除 copyToReadingZone
Phase 3: 组件层重构 → ImportPage 状态合并，ReaderPage 查询简化
Phase 4: 清理 → 旧表删除，旧代码移除，命名统一
```

## 二、Phase 1：数据库 Migration

### 2.2 步骤

#### Step 1：创建 readings 表

```sql
CREATE TABLE public.readings (
    id                text PRIMARY KEY,
    user_id           uuid NOT NULL REFERENCES public.profiles(user_id) ON DELETE CASCADE,
    title             text NOT NULL,
    author            text,
    format            text NOT NULL DEFAULT 'paste',
    cover_url         text,
    lang              text NOT NULL DEFAULT 'auto',
    source_url        text,
    sections          jsonb NOT NULL DEFAULT '[]',
    total_word_count  integer NOT NULL DEFAULT 0,
    section_count     integer NOT NULL DEFAULT 1,
    kind              text NOT NULL DEFAULT 'article' CHECK (kind IN ('article', 'book')),
    reading_status    text NOT NULL DEFAULT 'unread'
                      CHECK (reading_status IN ('unread', 'reading', 'in_progress', 'completed')),
    reading_started_at     timestamptz,
    reading_finished_at    timestamptz,
    origin            text NOT NULL DEFAULT 'imported'
                      CHECK (origin IN ('imported', 'shared', 'featured', 'featured_legacy', 'manual')),
    share_status      text NOT NULL DEFAULT 'private'
                      CHECK (share_status IN ('private', 'shared', 'public')),
    share_source_id   text,
    created_at        timestamptz NOT NULL DEFAULT now(),
    updated_at        timestamptz NOT NULL DEFAULT now(),
    deleted_at        timestamptz,

    UNIQUE (user_id, id)
);
```

**字段来源对照**：

| readings 字段 | 来源 |
|---|---|
| `id, user_id, title, author, format, cover_url, lang, source_url, sections, section_count, kind` | 两表共有，合并 |
| `total_word_count` | import_items.total_word_count（articles 的 word_count 通过 sections 计算得出，以 import_items 为准） |
| `reading_status` | 新增，根据迁移数据推断 |
| `reading_started_at, reading_finished_at` | 新增 |
| `origin, share_status, share_source_id` | 来自 import_items |
| `created_at, updated_at, deleted_at` | 合并时取最早 created_at、最新 updated_at |

#### Step 4：迁移 articles 数据（处理与 import_items 的关联）

对于每个 article，分两种情况：

**情况 A**：article 有 `source_import_id` 且对应的 import_item 已迁移

此 article 是 import_item 的"阅读副本"。合并不新建行，而是更新已迁移的 readings 行：

```sql
-- 为每对有 source_import_id 的 article，更新对应的 readings 行
WITH article_info AS (
    SELECT
        a.source_import_id,
        a.user_id,              -- 加入 CTE，直接用于 JOIN
        a.created_at AS article_created_at,
        a.updated_at AS article_updated_at,
        rm.completed,
        rm.section_id,
        rm.completed_sections,
        rm.progress_percent,
        rm.paragraph_index,
        rm.updated_at AS rm_updated_at
    FROM public.articles a
    LEFT JOIN public.reading_marks rm
        ON rm.article_id = a.id AND rm.user_id = a.user_id
    WHERE a.source_import_id IS NOT NULL
)
UPDATE public.readings r
SET
    reading_status = CASE
        WHEN ai.completed THEN 'completed'
        WHEN ai.paragraph_index IS NOT NULL OR ai.progress_percent > 0 THEN 'in_progress'
        ELSE 'unread'
    END,
    reading_started_at = LEAST(r.created_at, ai.article_created_at),
    reading_finished_at = CASE WHEN ai.completed THEN ai.rm_updated_at ELSE NULL END,
    updated_at = GREATEST(r.updated_at, ai.article_updated_at)
FROM article_info ai
WHERE r.id = ai.source_import_id
  AND r.user_id = ai.user_id;
```

作为独立行插入 readings：

**软删除记录处理策略**：以上 Step 3 和 Step 4 的 INSERT 均包含软删除记录（未过滤 `deleted_at IS NULL`），`deleted_at` 值一并迁移。策略理由：① 软删除记录可能是用户误删后需要恢复的；② bookmarks/reading_marks 可能引用已软删除的文章，排除它们会导致 Step 7 的 FK 约束建立失败。若生产环境中确无软删除记录，则迁移结果与过滤方案等价。

#### Step 5：迁移 bookmarks —— 重定向 FK

bookmarks 的 `article_id` 需要指向新的 readings 行。对于情况 A 的 article（已合并到 import_item 的 readings 行），bookmark 的 FK 指向 `source_import_id`；对于情况 B（独立 article），bookmark 的 FK 直接指向 article 的 id（已作为 reading 保留）。

```sql
-- 情况 A：bookmark 指向的 article 已合并到 readings（以 source_import_id 为 key）
UPDATE public.bookmarks b
SET article_id = a.source_import_id
FROM public.articles a
WHERE b.article_id = a.id
  AND a.source_import_id IS NOT NULL;

-- 情况 B：bookmark 指向的 article 直接变为 reading（id 不变），无需额外处理

-- reading_marks 同理
UPDATE public.reading_marks rm
SET article_id = a.source_import_id
FROM public.articles a
WHERE rm.article_id = a.id
  AND a.source_import_id IS NOT NULL;
```

**注意**：bookmarks 和 reading_marks 的复合 FK 仍然指向 `articles` 表。需要在 Step 7 统一处理。

#### Step 6：去重 reading_marks

可能出现同一用户对同一 reading 有多条 reading_mark（原一条在 article 上，一条通过 source_import_id 更新后冲突）。保留最新的：

```sql
DELETE FROM public.reading_marks rm1
USING public.reading_marks rm2
WHERE rm1.user_id = rm2.user_id
  AND rm1.article_id = rm2.article_id
  AND rm1.updated_at < rm2.updated_at;
```

#### Step 7：重定向 FK 约束

先删除旧的 FK，再建立新的 FK 指向 readings：

```sql
-- bookmarks
ALTER TABLE public.bookmarks
  DROP CONSTRAINT IF EXISTS bookmarks_user_id_article_id_fkey;

ALTER TABLE public.bookmarks
  ADD CONSTRAINT bookmarks_user_id_reading_id_fkey
  FOREIGN KEY (user_id, article_id) REFERENCES public.readings(user_id, id) ON DELETE CASCADE;

-- reading_marks
ALTER TABLE public.reading_marks
  DROP CONSTRAINT IF EXISTS reading_marks_user_id_article_id_fkey;

ALTER TABLE public.reading_marks
  ADD CONSTRAINT reading_marks_user_id_reading_id_fkey
  FOREIGN KEY (user_id, article_id) REFERENCES public.readings(user_id, id) ON DELETE CASCADE;
```

**注意**：bookmarks 和 reading_marks 表中的列名仍为 `article_id`。为了最小化变更面，该列名暂不改动——它只是列名，FK 指向已经改变。在 Phase 4 清理阶段再统一重命名。

```sql
CREATE OR REPLACE FUNCTION public.start_reading(p_reading_id text, p_user_id uuid, p_max_limit integer DEFAULT 5)
RETURNS void
LANGUAGE plpgsql
SECURITY DEFINER
AS $$
DECLARE
  v_active_count integer;
BEGIN
  SELECT COUNT(*) INTO v_active_count
  FROM public.readings
  WHERE user_id = p_user_id AND reading_status = 'reading' AND deleted_at IS NULL
  FOR UPDATE;

  IF v_active_count >= p_max_limit THEN
    RAISE EXCEPTION '阅读区已满（上限 % 本），请先放回一本书', p_max_limit;
  END IF;

  UPDATE public.readings
  SET reading_status = 'reading',
      reading_started_at = COALESCE(reading_started_at, now()),
      updated_at = now()
  WHERE id = p_reading_id
    AND user_id = p_user_id
    AND reading_status != 'reading'
    AND deleted_at IS NULL;
END;
$$;
```

**`delete_reading`**（替代 `delete_import_item`）：合并后简化为单表软删除 + 级联清理阅读数据。

```sql
CREATE OR REPLACE FUNCTION public.delete_reading(p_reading_id text)
RETURNS void
LANGUAGE plpgsql
SECURITY DEFINER
AS $$
BEGIN
  -- 软删除关联的 bookmarks
  UPDATE public.bookmarks
  SET deleted_at = now()
  WHERE article_id = p_reading_id
    AND user_id = auth.uid()
    AND deleted_at IS NULL;

  -- 清除 reading_mark
  DELETE FROM public.reading_marks
  WHERE article_id = p_reading_id
    AND user_id = auth.uid();

  -- 软删除 reading
  UPDATE public.readings
  SET deleted_at = now()
  WHERE id = p_reading_id
    AND user_id = auth.uid()
    AND deleted_at IS NULL;
END;
$$;
```
