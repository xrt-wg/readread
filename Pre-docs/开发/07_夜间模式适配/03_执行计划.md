## 风险与注意事项

1. **不能并行修改同一文件** — Phase 1-3 涉及的文件互不重叠（ReviewCard / ImportPage / ReaderPage 各自独立），Phase 4 与 Phase 2 共享 ImportPage 但修改区域不同（已完成的 vs 未完成的）。建议严格按 Phase 顺序执行，每完成一个 Phase 就 commit。

2. **CSS 变量引用必须在 style 属性中** — `var(--card-bg-warm)` 只能工作在内联 `style={{}}` 或 `<style>` / CSS 文件中，不能用于 Tailwind 的 `className`（除非配合 `bg-[var(--card-bg-warm)]` 语法，但本项目风格不一致，统一用内联 `style`）。

3. **`#3d3934` hover 色的选择逻辑** — 在日间模式下它显示为中等灰色 hover（与原来的 `#2d2926` 效果接近但稍浅），在夜间模式下它比背景 `#1a1814` 略亮，保持可辨识。如果视觉验收不满意，可微调。

4. **阴影对比度** — Phase 0 中 `--card-shadow` 的夜间值（`rgba(0,0,0,0.28)`）是初始建议值。实际效果可能需在真实设备上微调（±0.05）。

5. **不要改结构** — 本次修复只改颜色值。不调整 JSX 结构、不改变组件逻辑、不重构 props。保持 diff 最小化，降低回归风险。
