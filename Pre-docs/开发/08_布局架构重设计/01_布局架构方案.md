# ReadRead 布局架构重设计方案

> 日期：2026-07-20
> 状态：方案稿，待评审

---

## 一、设计目标

当前布局的核心问题不是某个组件没做好，而是**缺乏一个统一的空间系统**来编排所有视图。新架构的目标：

1. **一把尺子量到底** — 所有页面使用同一套宽度/间距/尺寸规则，消除跨视图的视觉跳跃
2. **Hub 是一个真正的"桌面"** — 四个功能区（阅读/回顾/书架/推荐）在同一空间系统内各有其位，而非四个独立 mini-app 的拼接
3. **阅读是核心，其余是支撑** — 空间节奏以"安静地阅读"为基准校准，管理/发现/回顾围绕这一基准展开
4. **进入和退出有呼吸** — 从 Hub 进入阅读/编辑器再返回，过渡平滑且有上下文保持

## 二、空间系统（Spatial System）

### 2.1 基准网格：8px

所有间距、尺寸基于 8px 的整数倍。

| 级别 | 值 | 用途 |
|---|---|---|
| xs | 4px | 紧密关联元素间（图标与标签） |
| sm | 8px | 列表项间距、卡片内元素间距 |
| md | 16px | 段落间距、区域间分隔 |
| lg | 24px | 内容区 padding、section 间距 |
| xl | 32px | 大区域分隔、页首/页尾留白 |
| 2xl | 48px | 视图切换后的顶部留白 |

### 2.2 内容宽度：两级体系

废除当前的 5 种 max-width（560/640/680/840/860），统一为两级：

| 级别 | 值 | 适用场景 | 理由 |
|---|---|---|---|
| **正文级** | `672px` | ReaderPage 正文、编辑器的预览/编辑区 | 18px 字号下约 70 字符/行，阅读舒适 |
| **列表级** | `672px` | Hub 所有 Tab 内容、书架、推荐、回顾 | 与正文级相同——切换时不发生宽度变化 |

> **设计决策**：为什么是 672px？
> - 可被 8 和 16 整除（方便间距计算）
> - 在当前 640px 和 680px 之间取中值
> - 18px 字号约 70 字符/行，处于可读性的甜区（65-75）
> - 一个宽度 = 零视觉跳跃。用户从书架切换到阅读正文时，内容区宽度不变

编辑器的侧边栏 + 编辑区布局作为特例，总宽仍为 672px，侧边栏从 200px 缩减到 172px（编辑区 500px 用于代码/文本输入）。

### 2.3 间距阶梯

```
组件内部间距:   8px (sm)
组件之间间距:  16px (md)
Section 内边距: 24px (lg)
Section 间间距: 32px (xl)
页面级留白:     48px (2xl) — 内容区顶部到 header、底部到页面边缘
```

### 2.4 圆角体系

| 元素 | 圆角 | 使用场景 |
|---|---|---|
| 按钮/输入框/标签 | `8px` | 小元素 |
| 卡片 | `12px` | 列表卡片、回顾闪卡 |
| 面板/容器 | `16px` | 推荐区容器、编辑面板 |
| 弹窗 | `20px` | Modal |

### 2.5 统一 Header 规范

```
Hub Header:     height: 56px,  内容居中对齐, 底边分隔线
Reader Header:  height: 48px,  内容居中对齐, 底边分隔线（滚动时隐藏）
Editor Header:  height: 56px,  内容居中对齐, 底边分隔线
```

所有 Header 内容区 `max-width: 672px`，左右自动居中。

## 三、页面架构

### 3.1 Hub 页（ImportPage 重设计）

#### 3.1.1 Header

```
┌──────────────────────────────────────────────────────┐
│  ReadRead                     📊 统计  ·  ☾  ·  👤  │  ← 56px, max-width 672px centered
├──────────────────────────────────────────────────────┤
│  阅读   回顾   书架   推荐                            │  ← Tab 栏, 带标签
├──────────────────────────────────────────────────────┤
│                                                      │
│              Tab 内容区 (672px)                       │  ← 统一宽度, 统一 padding-top: 32px
│                                                      │
```

**Header 变更**：
- 左侧：品牌 logotype（"ReadRead" + 金色书图标）
- 右侧：统计入口（点击展开下拉面板）+ 主题切换 + 用户
- **移除**：当前的 stats pill 横条（`3篇已读 | 12条收藏 | 5.2K词`）——这些数据移入阅读区 Tab 的迷你仪表盘卡片中，那里才是它们的语义归属
- **Tab 加上标签**：图标 + 文字，而非纯图标

#### 3.1.2 阅读区 Tab

```
┌─ 仪表盘卡片 ───────────────────────────────────── 672px ─┐
│  📖 3 篇在读    ⭐ 12 条收藏    📊 5.2K 词累计            │
└──────────────────────────────────────────────────────────┘
                          ↓ 24px
┌─ "继续阅读" 列表 ─────────────────────────────────────────┐
│  ┌──────────────────────────────────────────────────────┐ │
│  │ The Last Lecture           📖 放回    [进行中 34%]   │ │
│  └──────────────────────────────────────────────────────┘ │
│  ┌──────────────────────────────────────────────────────┐ │
│  │ Sapiens: A Brief History   📖 放回    [已读完 ✓]    │ │
│  └──────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

**空状态（无在读内容时）**：
- 仪表盘卡片仍然存在（显示 0/0/0）
- 下方展示一个友好的引导面板："导入一篇英文文章开始阅读"
- 保留示例文章按钮
- **移除** 700px 径向渐变 / 220px 巨型引号 / 80px Slogan 标题 → 这些品牌元素移至**首次使用引导**或**设置页的"关于"区**

#### 3.1.3 回顾区 Tab

```
┌─ 回顾头部 ──────────────────────────────────── 672px ─┐
│  今日待回顾：5 条    ·    上次回顾：2 小时前             │
└───────────────────────────────────────────────────────┘
                          ↓ 24px
┌─ 闪卡区 ──────────────────────────────────────────────┐
│                                                       │
│                   [ 回顾闪卡 ]                         │
│                   (min-height 自适应)                   │
│                                                       │
│              1 / 5    [生疏] [一般] [熟练]             │
│                                                       │
└───────────────────────────────────────────────────────┘
```

**变更**：
- 移除 `minHeight: 360px` 固定值 → 卡片高度由内容自然决定
- 卡片区宽 672px（非当前 560px），通过内部 padding 控制卡片视觉宽度
- 空状态文案精简

#### 3.1.4 书架 + 推荐区

布局保持现有逻辑，仅做空间系统适配：宽度 640px → 672px，间距使用新阶梯。

## 四、导航与浮动元素

### 4.1 右下角按钮合并

当前两个浮动按钮 → 合并为一个触发点：

```
┌──────┐
│  👤  │  ← AuthPanel（保持现有行为）
└──────┘
```

主题切换移入：
1. **Hub**：Header 右侧（日/夜图标），始终可见
2. **ReaderPage**：现有工具栏中的切换按钮，保持不变
3. 移除 App 层的独立浮动主题按钮

> 理由：主题切换是"一次性"设置——用户设定偏好后很少改动。浮动按钮的视觉突出度与它的使用频率不匹配。Header 中的位置足以覆盖"我需要改主题"的场景。

### 4.2 过渡动画

| 过渡 | 动画 |
|---|---|
| Hub → ReaderPage | 内容 `fade-up` 300ms |
| ReaderPage → Hub | 内容 `fade-up` 200ms |
| Hub → Editor | 内容 `fade-up` 250ms |
| Editor → Hub（确认放弃） | 内容 `fade-up` 200ms |
| Hub Tab 切换 | 内容区 `fade-up` 200ms |

## 五、全局对比：当前 vs 新架构

| 维度 | 当前 | 新架构 |
|---|---|---|
| 内容宽度种数 | 5 种 (560/640/680/840/860) | 1 种 (672px) |
| Header 高度 | 不一致 (py-4 / py-2.5 / py-6) | 统一 (Hub/Editor 56px, Reader 48px) |
| Tab 标签 | 纯图标 | 图标 + 文字 |
| 回顾区布局 | 固定 360px 盒子 | 自然流，高度由内容决定 |
| 阅读区空状态 | 巨型 Hero (400px+) | 紧凑仪表盘 + 引导面板 |
| 浮动按钮数 | 2 个（主题 + 用户） | 1 个（用户） |
| 编辑器宽度 | 860px（离群值） | 672px（统一） |
| 统计面板 | Header 中（全局） | 阅读区 Tab 内（语义正确） |
| 页面切换过渡 | 无 | fade-up 系列 |
