# ReadRead 布局架构方案 v2 — "画布上的平板"

> 日期：2026-07-20
> 状态：待评审

---

## 一、设计概念

```
┌── 显示器 = 画布背景（theme-responsive parchment）──────────────────┐
│                                                                    │
│                                                                    │
│                    ┌── 平板 ──────────────────┐                    │
│                    │  [Header: 品牌 + 设置]    │                    │
│                    │  ─────────────────────── │                    │
│                    │  [阅读] [回顾] [书架] [推]│                    │
│                    │  ─────────────────────── │                    │
│                    │                          │                    │
│                    │    内容区（内部滚动）      │                    │
│                    │                          │                    │
│                    │                          │                    │
│                    └──────────────────────────┘                    │
│                                                    ┌──┐           │
│                                                    │👤│ AuthPanel │
│                                                    └──┘           │
└────────────────────────────────────────────────────────────────────┘
```

**一句话**：整个显示器是一个温暖/沉静的画布，产品聚焦在一个居中、圆角、固定高度的"平板"中。平板内部的 Hub 可滚动。进入阅读时平板消失，文章全屏展开。读完返回平板。

## 二、空间参数

### 2.1 平板尺寸

| 属性 | 值 |
|---|---|
| 宽度 | `720px`（固定，不随 Tab 变化） |
| 高度 | `85vh`（`max-height: 900px`） |

> 设计决策：720px 宽度确保所有 Tab 内容（回顾闪卡、书架列表、推荐卡片）都有舒适的展示空间，且切换 Tab 时平板不会发生尺寸变化，保持视觉稳定。

### 2.2 平板与背景的关系

```
日间:
  背景: var(--parchment) = #faf4e8     ← 暖羊皮纸
  平板: var(--card-bg-warm) = #fffefc  ← 微微更亮，像纸铺在桌布上

夜间:
  背景: var(--parchment) = #1a1814     ← 深色画布
  平板: var(--card-bg-warm) = #1e1c19  ← 微微更亮，极微妙的区分
```

- 平板**无阴影**、**无边框**——边缘仅通过微妙的色差 + `border-radius: 24px` 来界定
- 背景上保留当前产品的 grain 纹理叠加层（`body::before`）

### 2.3 平板内部结构

```
┌─ 平板 720px / 85vh ──────────────────────────────────┐
│ ┌─ Header ────────────────────────────────────────┐ │
│ │  ReadRead                            ☾    👤    │ │ ← 56px, sticky
│ └─────────────────────────────────────────────────┘ │
│ ┌─ Tab 栏 ────────────────────────────────────────┐ │
│ │  📖 阅读  ·  🎓 回顾  ·  📄 书架  ·  ✨ 推荐     │ │ ← 44px, sticky
│ └─────────────────────────────────────────────────┘ │
│ ┌─ 内容区（flex-1, overflow-y: auto）─────────────┐ │
│ │                                                  │ │
│ │           当前 Tab 的内容                         │ │
│ │                                                  │ │
│ │                                                  │ │
│ └──────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────┘
```

- Header 和 Tab 栏**粘性固定**在平板顶部
- 内容区**内部滚动**
- 平板本身**不随内容增高**——`height: 85vh` 固定，居中对齐于视口

### 2.4 平板内部间距

| 区域 | 值 |
|---|---|
| Header 高度 | `56px`，`px-6` |
| Tab 栏高度 | `44px`，`px-6` |
| 内容区 padding | `pt-6 pb-12 px-8` |
| Tab 内容项间距 | `gap-4`（16px） |
| 卡片内部 padding | `px-5 py-4` |

## 三、模式切换：平板 ↔ 全屏阅读

### 3.1 阅读模式（突破平板）

```
打开文章时:
  平板 scale(0.97) + opacity(0) → 消失（200ms）
  阅读页 opacity(0→1) → 全屏展开（300ms）

关闭文章时:
  阅读页 fade out（200ms）
  平板 scale(0.97→1) + opacity(0→1) → 回归（300ms）
```

阅读页全屏渲染，使用 `max-width: 680px` 居中正文。

### 3.2 编辑器（同样突破平板）

点击书架「编辑」→ 编辑器全屏展开。Header 统一规范（56px），内容区 `max-width: 880px`。

### 3.3 画布上的唯一例外

AuthPanel（`fixed bottom-5 right-5`）始终在画布上。它是平板之外唯一可见的 UI 元素。

## 四、各 Tab 内容布局（平板内部）

### 4.1 阅读区

```
┌─ 仪表盘卡片 ──────────────────────────────────────┐
│  📖 3 篇在读    ⭐ 12 条收藏    📊 5.2K 词累计      │
└────────────────────────────────────────────────────┘

┌─ 继续阅读列表 ────────────────────────────────────┐
│  ┌──────────────────────────────────────────────┐ │
│  │ The Last Lecture        📖 放回  [34% ████ ]│ │
│  └──────────────────────────────────────────────┘ │
│  ┌──────────────────────────────────────────────┐ │
│  │ Sapiens                  📖 放回  [✓ 已读完] │ │
│  └──────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────┘
```

空状态：仪表盘卡片仍展示（0/0/0），下方引导面板 + 示例文章按钮。不再有 Hero 区的巨型装饰。

### 4.2 回顾区

平板内布局。卡片居中，高度由内容自然决定（不硬编码 360px）。进度条、计数器、反馈按钮在卡片下方。

### 4.3 书架 / 推荐区

平板内布局。列表/卡片布局保留现有逻辑，间距适配 16px gap。

## 五、实施架构

### 5.1 App.jsx 结构变化

```jsx
// 当前:
<div className="min-h-screen" style={{ backgroundColor: 'var(--parchment)' }}>
  <AuthPanel />
  {article ? <ReaderPage /> : <ImportPage />}
</div>

// 新架构:
<div className="canvas" style={{
  minHeight: '100vh',
  backgroundColor: 'var(--parchment)',
  display: 'flex',
  alignItems: 'center',
  justifyContent: 'center',
}}>
  <AuthPanel />  {/* 画布上唯一的外部元素 */}

  {article ? (
    <ReaderPage />           // 全屏突破
  ) : editingItem ? (
    <ImportItemEditor />     // 全屏突破
  ) : (
    <div className="tablet"  // 平板容器
      style={{
        width: '720px',
        height: '85vh',
        maxHeight: '900px',
        background: 'var(--card-bg-warm)',
        borderRadius: '24px',
        overflow: 'hidden',
        transition: 'width 0.4s cubic-bezier(0.16,1,0.3,1)',
      }}>
      <ImportPage inTablet />  {/* ImportPage 感知平板模式 */}
    </div>
  )}
</div>
```

### 5.2 ImportPage 适配

- 不再 `min-h-screen` → 改为 `h-full flex flex-col`
- Header 变为平板内部 Header：品牌 + 主题 + 用户
- Tab 栏粘性固定
- 内容区 `flex-1 overflow-y-auto`

### 5.3 ReaderPage 适配

- 保持现有布局结构，`min-h-screen` 改为全屏
- 正文 `max-width: 680px` 居中

### 5.4 平板宽度

平板宽度固定 720px，不随 Tab 切换变化。

## 六、与当前布局的对比

| 维度 | 当前 | v2 |
|---|---|---|
| 页面概念 | 整页滚动 | 固定平板 + 内部滚动 |
| 内容宽度 | 5 种 | 平板 720px 固定，阅读 680px / 编辑 880px 全屏 |
| 背景角色 | 页面底色 | 画布，有纹理 |
| 平板/容器 | 无 | 圆角卡片，仅色差区分 |
| Header | 随页面变化 | 平板内 sticky |
| 阅读时 | 页面内切换 | 平板消失，全屏展开 |
| 浮动元素 | 2 个 | 1 个（AuthPanel） |
