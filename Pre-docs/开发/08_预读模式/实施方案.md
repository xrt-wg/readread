## 详细设计

### 1. ReaderPage.jsx

#### 1.1 新增状态

```javascript
const [preReadMode, setPreReadMode] = useState(false)
```

默认 `false`，不持久化。

#### 1.2 handleSelection 分支

在现有选区处理逻辑（第 169 行 `const selected = ...` 之后）插入分支：

```javascript
// 预读模式：划词即收藏，无弹窗
if (preReadMode) {
  const selType = detectSelectionType(selected)
  const isShort = selType === 'word' || selType === 'phrase'
  // ...提取 paraIndex, sectionId, contextSentence, charOffset（复用现有逻辑）

  const bm = createBookmark({
    type: selType,
    text: selected,
    contextSentence: isShort ? findContainingSentence(paraText, selected) : null,
    articleId,
    paragraphIndex: paraIndex,
    charOffset,
    sectionId: sectionId ?? null,
    sectionHeading: (sectionId ? effectiveSections.find(s => s.id === sectionId)?.heading : null) ?? null,
  })

  try {
    const savedBookmark = await saveBookmark(bm, { canUseCloudLibrary, userId })
    await loadReaderState()
    // 异步触发 AI 翻译（不阻塞）
    translateBookmark(savedBookmark, async () => {
      await loadReaderState()
    })
  } catch (e) {
    if (isLibraryAccessError(e)) refreshAuthState()
    setLibraryError(resolveLibraryErrorMessage(e, '收藏失败'))
  }

  window.getSelection()?.removeAllRanges()
  return  // ← 关键：直接返回，不设置 popup，不调用 translate()
}
```

**说明：**
- 复用 `handleBookmark`（第 224-256 行）的核心逻辑，但内联在 `handleSelection` 中以避免先设置 popup 再多一步点击
- `translateBookmark` 异步调用不 await — 翻译在后台进行，不阻塞用户继续标注
- `loadReaderState()` 在收藏保存后立即调用一次（让下划线出现），翻译完成后再调用一次（让翻译内容更新）
- `window.getSelection()?.removeAllRanges()` 清除选区，提供自然的"操作完成"体感

#### 1.3 新增：预读模式关闭时批量翻译

```javascript
const handleTogglePreRead = useCallback(async (newMode) => {
  setPreReadMode(newMode)
  if (!newMode) {
    // 关闭预读模式 → 批量翻译所有 pending 收藏
    const pending = bookmarks.filter(b => b.translationStatus === 'pending')
    for (const bm of pending) {
      try {
        await translateBookmark(bm, async () => {})
      } catch { /* 单个失败不阻塞后续 */ }
    }
    await loadReaderState()
  }
}, [bookmarks, translateBookmark, loadReaderState])
```

**说明：**
- 串行翻译，避免 API 并发限制
- 单个翻译失败不阻塞后续
- 全部完成后一次性 `loadReaderState()` 刷新

#### 1.4 useEffect：预读模式下的新收藏自动翻译

预读模式中，每次 `handleSelection` 创建的 bookmark 已经单独调用了 `translateBookmark`。因此关闭预读时的批量翻译主要覆盖以下边缘情况：
- 之前的 pending 收藏（非本次预读产生的）
- 翻译失败需要重试的收藏

#### 1.5 传递 props 给 ReaderHeader

在 ReaderPage 渲染 ReaderHeader 处新增两个 prop：

```jsx
<ReaderHeader
  // ...现有 props
  preReadMode={preReadMode}
  onTogglePreRead={() => handleTogglePreRead(!preReadMode)}
/>
```

#### 2.2 新增按钮

在现有按钮组中（主题切换按钮旁）添加：

```jsx
<button
  onClick={onTogglePreRead}
  title={preReadMode ? '关闭预读模式' : '预读模式：划词即收藏，无弹窗'}
  className="flex items-center justify-center rounded-lg transition-all"
  style={{
    width: 30, height: 30,
    background: preReadMode ? 'rgba(196,154,60,0.18)' : 'transparent',
    border: `1px solid ${preReadMode ? 'rgba(196,154,60,0.45)' : 'var(--surface-border)'}`,
    cursor: 'pointer',
    color: preReadMode ? 'var(--gold)' : 'var(--ink-muted)',
  }}
  onMouseEnter={(e) => {
    if (!preReadMode) {
      e.currentTarget.style.background = 'var(--hover-bg)'
      e.currentTarget.style.color = 'var(--ink)'
    }
  }}
  onMouseLeave={(e) => {
    if (!preReadMode) {
      e.currentTarget.style.background = 'transparent'
      e.currentTarget.style.color = 'var(--ink-muted)'
    }
  }}
>
  <ScanEye size={13} />
</button>
```

图标选择 `ScanEye`（来自 lucide-react，语义为"扫读/浏览"），激活态为金色，与收藏按钮风格一致。

> 如 `ScanEye` 不可用，备选 `Eye` 或 `Glasses`。

## 数据流总览

```
预读模式 ON：

用户划词
  → handleSelection
    → detectSelectionType / findContainingSentence / getCharOffset
    → createBookmark({ text, contextSentence, ... })
    → saveBookmark() → loadReaderState() → 文本出现下划线 ✓
    → translateBookmark() 异步启动 AI 精译
    → removeAllRanges()
  → return（不设 popup，不调 translate）

预读模式 OFF：
  → handleTogglePreRead(false)
    → for pending bookmarks: translateBookmark() 串行
    → loadReaderState() 一次性刷新
```

## 验证清单

| 验证项 | 预期结果 |
|--------|----------|
| 预读模式 OFF + 划词 | 弹窗正常出现，翻译正常 |
| 预读模式 OFF + 划词 + 点收藏 | 弹窗先展示，点收藏后收藏卡触发 AI 翻译（现有行为不变） |
| 预读模式 ON + 划词（单词） | 无弹窗；文本出现收藏下划线；收藏面板中出现 pending 词条 |
| 预读模式 ON + 划词（句子/段落） | 同上 |
| 预读模式 ON + 连续划多个词 | 每个都静默收藏，不互相阻塞 |
| 预读模式 ON → OFF | pending 收藏逐个完成翻译，收藏面板中翻译出现 |
| 预读模式 ON → 离开文章 → 再进入 | 上次 pending 的收藏保持 pending（或如果翻译已完成则显示翻译） |
| 预读模式 ON → 刷新页面 | 模式重置为 OFF（不持久化） |
| 预读模式切换按钮样式 | 激活态金色高亮，非激活态与其他按钮一致 |
