# 订阅机制说明

> 日期：2026-09-23
> 性质：机制规则与语义说明（非实施文档）
> 关联：[01_讨论和决策记录](01_讨论和决策记录.md)

## 0. 定位与范围

本文定义订阅机制的完整规则与语义，是后续《实施方案》的依据。只讲「机制」（谁、何时、因何、得到什么、失去什么），不讲技术实现；数值参数以「待定」占位，机制逻辑已定死。

## 1. 产品与用户

语言学习阅读器——「读自己感兴趣的内容，边读边学英语」。目标用户：中文母语、有英语阅读习惯、自主学习、不功利的英语学习者。

## 2. 身份模型

- 两个身份：Free / Pro。
- Pro 的两个来源：付费购买；或社区贡献（推荐上架换时长）。
- Pro 按天计时，到期自动回 Free，无惩罚。

## 3. 权益边界

核心闭环（两身份完全一致、永不降级）：划词弹窗直译、收藏 + AI 精译、SRS 复习。

差异只在容量：

| 权益 | Free | Pro |
|---|---|---|
| 导入 | 终身累计 N 篇（待定） | 无限 |
| 收藏 | 每周 N 条（待定） | 无限 |
| 同时在读 | 5 本（可配） | 更多（待定，本次不生效） |

## 4. 核心概念区分

| 概念 | 是什么 | 付费意愿 |
|---|---|---|
| 持有（存储） | 书架同时放几本 = 存量，删可释放 | 弱 |
| 导入（动作） | 把新内容带进来 = 燃料，核心循环入口 | 强 |
| 收藏（输出） | 学习产生的生词 = 产出 | 中（受速率限制） |

关键判断：导入是**燃料**不是**存储**。核心循环「发现 → 导入 → 阅读 → 学习 → 再发现」里，导入是入口；限制导入次数 = 限制核心行为本身。重导旧内容给不了新学习材料，所以「更多导入次数」是真实且强的付费意愿。

## 5. 两个杠杆

### 5.1 导入额度（累计总数）= 转化引擎

- 定义：终身累计可导入 N 篇，不重置。
- 封的是什么：燃料 / 核心入口。
- 成本：≈ 零（导入不产生外部 API 成本）。
- 超额：撞累计墙，不能再导，升级解锁。
- 调法提示：免费额度必须给足，别在验证期卡死探索者。

### 5.2 收藏额度（每周软限）= 成本闸门

- 定义：每周 N 条，北京时间周一 0 点重置，每条收藏计 1（不分 word/phrase/sentence/paragraph）。
- 封的是什么：学习速率。
- 成本：高（每条收藏触发一次 LLM 精译）。
- 超额：禁收藏，但不禁划词翻译。
- 角色：次要转化（可等待重置），主要控成本。

两者互补：用「燃料总量」做转化（成本为零、意愿最强），用「学习速率」控成本（成本最高、意愿次要）。

## 6. 社区激励

- 触发：推荐内容「上架」才计，仅提交 / 过审不计。
- 奖励：每上架 1 篇 = N 天 Pro。
- 叠加：赚取时长与购买时长累加到到期日之后。
- 到期：自动回 Free。
- 防刷：管理员审核 + 提交频率限速 + 每月赚取上限 M 天。

## 7. 超额处理

- 收藏超额：禁收藏，但不禁划词翻译（划词弹窗永远在线）。
- 导入超额：撞累计墙，不能再导（升级解锁）。
- 铁律：核心闭环永不降级。

## 8. 未来钩子（Pro 专属，当前不实现）

PDF 导入、学习统计报告、连续打卡。

## 9. 待定参数

| 参数 | 调法提示 |
|---|---|
| 导入累计总数 N | 要给足，别在验证期卡死探索者 |
| 每周收藏额度 N | LLM 成本承受力 |
| 上架奖励天数 N | 激励强度 vs 审核人力 |
| 每月赚取上限 M | 防刷 |
| 同时在读（Pro） | 差异化强度 |
| Pro 价格 | 市场 + 成本 |

## 10. 留意项

生词本 ↔ 书架的独立性：未来若把「学习积累」当资产变现，生词本须独立于书架（删书不毁学习）。这是一个数据模型层面现在就该留意的决策。
