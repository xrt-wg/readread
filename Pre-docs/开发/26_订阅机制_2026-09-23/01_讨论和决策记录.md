## 定位（顶层判断）

当前阶段唯一目标是**尽快完整跑通整个产品**。

## 核心决策

1. **订阅卖「更多」不卖「功能」**：学习闭环（读得懂 / 记 / 复习）全免费、永不降级；付费只解锁「更多」。
2. **免费档 = 永久免费**（不过期），不是试用，也非无限容量——容量上限与「不过期」兼容。
3. **身份模型 = 两身份，Pro 两来源**：Free / Pro；Pro 来自付费购买或社区贡献（推荐上架换时长），按天计时、到期自动回 Free。
4. **两个杠杆分工**：
   - **导入额度（累计总数）= 转化引擎**：封「燃料」（核心入口），终身累计 N 篇。导入是燃料不是存储，限制导入 = 限制核心行为，付费意愿强。
   - **收藏额度（每周软限）= 成本闸门**：封「学习速率」，每周 N 条（北京时间周一 0 点重置），每条计 1。每条收藏触发一次 LLM 精译，此额度止住无上限补贴。
5. **超额只禁收藏、不禁划词翻译**：划词弹窗直译永远在线，「读得懂」不降级。

## 当下判断

跑通产品期间，**不做任何「写死免费、堵死未来付费墙」的改动**——保留翻译来源标记、保留翻译降级兜底；顺手时把「同时 5 本在读」从硬编码改为可配置（非必须，不新增工作）。
