## 二、核心改动：ReaderPage.jsx

### 2.1 `showHoverCard` 入口 gate

当前实现（约第 113–117 行）：

```js
const showHoverCard = useCallback((bm, el) => {
  clearTimeout(hideTimerRef.current)
  if (bm) setHoverBookmark({ bookmark: bm, el })
  else hideTimerRef.current = setTimeout(() => setHoverBookmark(null), 150)
}, [])
```

改为：

```js
const showHoverCard = useCallback((bm, el) => {
  if (preReadMode) return                    // ← 预读模式下禁用收藏悬浮卡
  clearTimeout(hideTimerRef.current)
  if (bm) setHoverBookmark({ bookmark: bm, el })
  else hideTimerRef.current = setTimeout(() => setHoverBookmark(null), 150)
}, [preReadMode])
```

**改动点：**

1. 函数体首行加 `if (preReadMode) return`
2. 依赖数组 `[]` → `[preReadMode]`

**说明：**

- `preReadMode` 声明于同文件第 103 行，早于 `showHoverCard`（第 113 行），作用域内可直接引用
- `showHoverCard` 是唯一把**收藏对象（非 null）**写入 `hoverBookmark` 的入口（其余两处 `setHoverBookmark(null)` 仅做清空），gate 后 `hoverBookmark` 在预读模式下恒为 `null`
- 依赖数组变化使 `showHoverCard` 在模式切换时重建；`MarkdownContent` 用 `onHoverRef.current` 承接、`ParagraphRenderer` 为 `memo`，重建成本仅发生在模式切换瞬间，可忽略

### 2.2 渲染条件补 `!preReadMode`（双保险）

源头 gate 阻止「产生」悬浮卡，但无法关闭「切换那一刻已残留」的 `hoverBookmark`。为把「预读模式下绝不渲染悬浮卡」升级为声明式不变量，渲染条件补一个兜底：

```diff
-      {hoverBookmark && !popup && (
+      {hoverBookmark && !popup && !preReadMode && (
```

**说明：**

- 无论 `hoverBookmark` 出于何种时序残留，预读模式下都绝不渲染
- 普通模式（`preReadMode = false`）行为完全不变，零回归
- 与源头 gate 互补：gate 管「不产生」，条件管「不渲染」

### 2.3 无需改动项（确认）

| 项 | 说明 |
|----|------|
| `TranslationPopup` | 预读模式下 `popup` 从不被设置，本就无翻译弹窗 |
| 高亮 `<span>` 的 `onMouseEnter/onMouseLeave` | 触发 `showHoverCard` 后变成空操作，无害，无需移除 |
| `BookmarkHoverCard` 组件本身 | 复用普通模式逻辑，不改 |
| `handleTogglePreRead` | 关闭预读时的批量翻译逻辑不变 |

## 三、数据流

```
普通模式（preReadMode = false，现状不变）：
  悬浮高亮 → showHoverCard → setHoverBookmark → 渲染 BookmarkHoverCard

预读模式（preReadMode = true，本次改动）：
  悬浮高亮 → showHoverCard → if (preReadMode) return（源头 gate，不产生 hover 状态）
  渲染     → hoverBookmark && !popup && !preReadMode（条件兜底，绝不渲染）
  划词     → saveBookmark → loadReaderState → 下划线出现（不变）
           → translateBookmark 后台异步（不变）
```

## 四、预期效果

| 场景 | 之前 | 之后 |
|------|------|------|
| 预读模式 + 悬浮单词高亮 | 弹悬浮卡 | **不弹** |
| 预读模式 + 悬浮句子高亮 | 不弹（命中区域问题） | **不弹**（主动禁用） |
| 预读模式 + 划词 | 静默收藏 | 静默收藏（不变） |
| 普通模式 + 悬浮高亮 | 弹悬浮卡 | 弹悬浮卡（不变） |
| 普通模式 + 划词 | 翻译弹窗 → 可选收藏 | 不变 |

行为一致性：预读模式下单词/句子**都不弹**，消除了原来的不一致。
