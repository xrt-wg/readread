## 一、请求说明

本次实施将阅读区书籍分页粒度从「章（depth 0 + 子树合并）」改为「有正文节」：每个 `body` 有正文（text 或 markdown 任一非空）的 section 独立成一页；纯容器节全场景不进正文流（A2，含非分页单节书），中间节点父正文独立成页（B1 由保序 filter 自动满足）。

请审核方在实施完成后，**对照本文档 §三「对照点」逐项核验代码与预期是否一致**，重点确认「一致性红线」无违例。

## 四、验收标准

1. **分页单位**：多节书籍按「有正文节」逐节分页；`上一节/下一节` 顺序正确、边界禁用正确；页码 = 节序号 / 有正文节总数。
2. **容器节剔除（全场景）**：「第一部」这类无正文节不出现在正文页（含非分页单有正文节书），但出现在目录侧栏；点击容器节跳向其第一个有正文后代。
3. **父正文独立页**：中间节点父正文（如「第三章」章引言）单独成页，且排在其首个子节（3.1）之前。
4. **单节书**：有正文节数 = 1 时 `paginated=false`，连续流、不出现翻页与目录侧栏。
5. **进度/跳转/恢复**：进度条按节加权；「跳到阅读标记」「跳转段落」「目录点击」均定位到正确节并正确滚动。
6. **目录高亮**：侧栏高亮当前节（精确到节，非章 lead）。
7. **空正文书**：`contentSequence.length === 0` 时回退 `effectiveSections`，正文区不空渲染。
8. **编辑器目录**：D1 缩进无回归（本次不改 SectionContentEditor）。

## 五、风险与回滚

- **索引单位遗漏**：`currentChapterIdx`/`chapters` 相关引用漏改会导致跳转/进度错位——审核须按 §三 C1~C19 逐项核对。
- **翻页变碎**：节数多的书翻页次数增加，属已接受的产品决策。
- **P1(b) 行为变化**：非分页单章书若含空容器标题，改后不再显示该标题（纠正，非回归）。
- **回滚**：纯前端改动，回退 ReaderPage.jsx / ReaderHeader.jsx 即可，无数据/迁移副作用。
